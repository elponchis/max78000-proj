# 평가 기준 변경 제안서 — 시험 정답을 청취로 확정한다 (2026-10-09, 제안, 실행 전)

> ⚠️ 이 문서가 답해야 할 원래 요구사항("지난 프롬프트의 1번") 원문은 이 세션에 도착하지 않았다. 아래는
> `label-audit.md` 6~7절의 결정과 2026-10-09 지시("위 규칙을 반영해 작성")에서 구성한 것이다. 원문과 다른 부분은
> 고쳐 달라. **청취 결과(7.1 세트 470창)가 나오기 전까지 실행하지 않는다.**

## 1. 왜 바꾸는가

- 기존 시험셋의 **glass 창은 `Shatter` 클립에서 어택이 가장 센 자리**로 뽑았고(`label-audit.md` 3절), 청취 결과
  PANNs 점수가 매우 낮은 창 15개 중 12개가 유리 파손이 아니었다 (6절). 시험셋 glass 221창 중 111창(50%)이 그
  구간이다. 즉 **시험셋 glass 정답의 상당수가 유리가 아닐 수 있고**, 지금까지의 glass recall·macro-F1 은 그 창들을
  맞히지 못한 만큼 **낮게 나온 것**이다 (v2.1 간격 400 glass recall 52.9%).
- 외부 세트의 scream 양성은 AudioSet `Screaming` 주석을 그대로 믿은 것인데, 같은 주석의 학습분에서 PANNs 매우 낮음
  14창 중 10창이 비명이 아니었다. 외부 scream 양성 74~81창의 절반이 그 구간이다. **외부 scream recall 15~23% 는
  정답이 틀린 만큼 낮게 나온 것**일 수 있다.
- 따라서 "모델이 못 맞힌다" 와 "정답이 틀렸다" 를 가르지 않고는 v3/v3.1 의 실패도, 다음 판의 성공도 판정할 수 없다.

## 2. 무엇을 바꾸는가

### 2.1 정답 확정 방식

| 대상 | 지금 | 바꾼 뒤 |
|---|---|---|
| 기존 시험셋 glass 221창 | `Shatter` 클립 + onset 순 선별 → 전부 양성 | **사용자 청취** O/X/? — O 만 양성 |
| 외부 세트 scream (v1 ∪ 실사용 130창) | AudioSet 주석 → 정의별 양성 | **사용자 청취** O/X/? — O 만 양성 (정의별 양성 조건은 유지) |
| 외부 세트 glass 74창 | AudioSet 주석 → 양성 | **사용자 청취** O/X/? |
| 기존 시험셋 siren·scream·dog_bark, 외부 siren·dog_bark | 그대로 | **그대로** (이번 범위 밖; scream 시험셋은 다음 차례) |
| 배경(음성) | 그대로 | **그대로** — X 창을 배경으로 옮기지 않는다 |

판정 규칙: **O → 양성**, **X → 그 클래스에서 제외 (배경으로 옮기지 않는다; 채점에서 빠진다)**, **? → 평가에서 제외**.
X 와 ? 는 둘 다 채점에서 빠지지만 기록은 구분한다 (X 는 "그 클래스가 아님" 이 확인된 창, ? 는 미확정).
PANNs 점수는 **시험 정답에 쓰지 않는다** — 청취 세트의 파일명에 점수·출처가 없고, 대조 창(PANNs ≥ 0.50, 세트당 15)이
섞여 있어 청취가 점수에 끌려가지 않는다.

### 2.2 비명 정의 (사용자 결정, `label-audit.md` 6.2)

- 아기 울음(`Baby cry, infant cry` 라벨 보유 구간)은 비명이 아니다 → 비명 양성에서 빼고 **배경**으로 둔다.
  외부 `g9Qah25_yH0_14000` 이 해당한다 (v1 정의 scream 양성 → 배경).
- 놀라서 지르는 날카로운 외침은 비명이다 (청취 시 O).
- 군중 동반 비명(실사용 정의 양성, v1 정의 음성)은 정의별 규칙을 유지하고, 청취 O/X 는 그 위에 겹친다.

### 2.3 주 기준

외부 세트의 주 정의는 v3.1 과 같이 **실사용(real31)** 을 유지하되, 청취 확정 후의 양성·음성으로 채점한다
(`real31L` 로 표기). v1 정의(`v1eqL`)는 병기. 기존 시험셋은 `testL` (glass 만 바뀜).

## 3. 영향 (실행 전 예상 — 수치는 청취 후 채운다)

- 기존 시험셋 glass 양성이 221 → 약 110~130 으로 줄 수 있다 (PANNs 매우 낮음 111창의 대부분이 X 라면). 양성이 줄면
  glass recall 의 CI 가 넓어진다 — 원본 수 기준(clip 단위)으로 다시 센다.
- **기존 체크포인트는 그대로 두고 라벨만 바꿔 재채점**한다 (v1, v2.1, v3, v3.1 전부; `eval_v3.py` 에 라벨 옵션 추가).
  시험셋 @300/h 문턱값은 배경에서 잡으므로 **문턱값은 바뀌지 않는다** — recall·F1 만 바뀐다.
- v3·v3.1 의 사전 등록 판정은 **당시 라벨로 내린 판정 그대로 둔다** (사후 변경 금지). 새 라벨의 수치는 별도 표로
  "재채점" 이라 적는다.
- 논문 본 표: 재채점 결과가 나온 뒤 **사용자가** 본 표 라벨을 정한다. 이 문서는 제안이다.

## 4. 절차 (청취 결과가 나온 뒤)

1. `verdict_sheet.csv` 를 받아 `key.csv` 와 합쳐 `data/external_eval/labels_listened.csv` (git 제외) 를 만든다.
   O/X/? 분포와 대조 창(PANNs ≥ 0.50)의 O 비율을 적는다 — 대조 창의 O 비율이 낮으면 청취 기준 자체를 다시 본다.
2. `eval_external.labels(M, "real31L"/"v1eqL")`, 시험셋 로더에 `glass` 제외 목록을 넣는 `testL` 옵션을 추가한다.
   창 제외는 **채점 단계**에서 한다 (샤드는 건드리지 않는다 — 비트 일치 검사가 그대로 유효해야 한다).
3. 전 판 재채점 → `docs/results/eval-baseline-change.md` 5절에 표 (v2.1 vs v3.1, 옛 라벨 vs 새 라벨 나란히).
4. 그 다음에야 `v4-distill-design.md` 의 성공 기준(새 라벨 기준)을 확정하고 실행한다.

## 7. 외부 세트를 주 기준으로 쓰면 — 개발용/최종용 분할안

**문제.** 외부 세트가 주 기준이 되면 그 결과를 보고 다음 설계를 바꾸게 되고 (v3.1 → v4 의 비명 정의·정리 규칙이 이미
그 경로다), 외부 세트가 더는 "보지 않은 데이터" 가 아니게 된다.

**안.** 영상(ytid) 단위로 결정적 해시(`sha1(ytid) % 2`)로 반을 가른다 — 창 758개가 영상 758개(세그먼트당 1창)라 영상
분할 = 창 분할이다. 한쪽(개발용)은 설계 반복에 쓰고, 다른 쪽(최종용)은 논문 직전 **한 번**만 채점한다.

| 반 | 영상=창 | 배경 | real31 양성 siren / glass / scream / dog | v1eq 양성 | real31 음성 |
|---|---:|---:|---|---|---:|
| 개발용 (해시 0) | 381 | 135 | 48 / 41 / 41 / 37 | 65 / 41 / 42 / 37 | 197 |
| 최종용 (해시 1) | 377 | 129 | 39 / 33 / 33 / 50 | 56 / 33 / 39 / 50 | 205 |
| 전체 | 758 | 264 | 87 / 74 / 74 / 87 | 121 / 74 / 81 / 87 | 402 |

(청취 확정 뒤 scream·glass 양성은 더 줄어든다 — 매우 낮음 비율이 절반이면 반쪽당 scream·glass 양성이 **20창 안팎**.)

**3시드 분해능.** 지금(전체 758창)의 외부 F1 시드 간 sd 는 0.016~0.037 (v3·v3.1 ④·간격 400 실측), 조건 A 의 CI
반폭은 0.051~0.079. 창을 반으로 줄이면 표본 잡음이 √2 배 → 반폭 **0.07~0.11**. 실제로 본 효과 크기는 v3 간격 400
+0.11 (겨우 걸림), ④ +0.04 (못 가림). 배경 130창에서 @300/h 는 2.7창이라 맞춤 지점의 해상도도 거칠어진다.
양성 20~40창에서 클래스별 recall 은 1창 = 2.5~5 pp 다.

**권고: 지금 세트는 나누지 않는다.** 이유 셋.
1. 분해능이 이미 한계다 (④ 크기의 효과를 못 가린다). 반으로 나누면 간격 400 의 +0.11 도 못 가린다.
2. glass 는 AudioSet eval strong 의 **84구간 전부**를 이미 썼다 (`external-set.md` 3절) — 최종용을 새로 받아 보충할
   수 없는 클래스다.
3. 대신 **절차로 막는다**: (가) 외부 세트는 사전 등록된 판정 시점에만 채점한다 (이미 그렇게 하고 있다), (나) 외부 결과를
   보고 바꾼 설계 결정은 문서에 "외부 세트 근거" 라고 표시한다 (v3.1 은 시험셋 근거라고 적었고, v4 정리 규칙은
   청취 근거다), (다) 논문에는 외부 세트를 "같은 출처의 보지 않은 영상" 이 아니라 **"설계 반복에 쓴 개발용 외부
   세트"** 로 정직하게 쓴다.

**대안 (사용자가 최종용이 꼭 필요하다고 보면)**: siren·scream·dog_bark 는 eval strong 에 뽑지 않은 구간이 남아 있으므로
(실사용 정의로 클래스당 100개만 뽑았으므로 모집단에 남은 구간이 있다 — 정확한 수는 외부데이터 세션의 모집단 표로 확인) **external_v2** 를 새 영상으로 받아 최종용으로 둔다. glass 는 불가 — glass 만
예외로 전체를 개발용에 두고 논문에 그렇게 적는다. 이 다운로드는 외부데이터 세션 몫이고, 받기 전에 ytid 가 train_v2 와
겹치지 않는지 확인한다.
