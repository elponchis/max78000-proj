# 잡음 눈금 — 장치 차이와 시드 차이의 크기 (2026-09-27)

**개선폭을 해석하려면 먼저 눈금이 필요하다.** B 가 +0.070 을 냈을 때 그것이
실제 개선인지 시드 변동인지 판단할 수 없었다. 이 문서가 그 기준이다.

전부 WSL2 CPU, 150에폭, 실행당 21~22분. 비교는 `tools/compare_runs.py`,
지표는 **고정 오경보 지점의 macro-F1** (argmax 아님).

## 2. 결론 셋

### 2.1 CPU 학습은 문제가 없다 — 장치 차이가 시드 잡음의 1/25 이다

④ 시드 1 의 CPU/GPU 차이는 300/h 에서 **0.002** 이고, 같은 모델의 시드 간 차이
**0.052** 의 약 1/25 다.

→ **`g8-first-comparison.md` 4.3.1 과 `g8-d1-filterbank.md` 4장의 "CPU 학습이라
소수점 비교 금지" 경고는 과했다.** 장치 차이는 측정 가능한 수준 아래이므로
CPU 학습 결과를 GPU 결과와 같은 표에 놓아도 된다. 두 문서를 고쳤다.
⚠️ 1000/h 에서는 +0.016 으로 조금 크다. 시드 잡음(0.077)보다는 여전히 작지만,
장치 차이가 정확히 0 이라고 주장하지는 않는다.

### 2.2 ④의 시드 잡음이 크다 — 300/h 에서 0.052, 1000/h 에서 0.077

**이것이 이번 측정의 핵심 눈금이다.** 되짚으면:

> **B 의 +0.070(단일 시드)은 이 잡음 폭 안이다.** B 가 실제로 개선했다고
> 말할 근거가 아직 없다 → **B 시드 2 를 돌리는 중**이다.

⚠️ 시드 2개로 구한 "차이" 는 분산 추정이 아니다. 표준편차를 말하려면 최소
3~5회가 필요하다. 여기서는 **"적어도 이만큼은 흔들린다"** 는 하한으로만 쓴다.

### 2.3 D-1 향상은 잡음보다 크다 (+0.136 vs 0.052)

시드 평균 대비 시드 평균으로 **+0.136**, ④ 시드 폭의 약 2.6배다. 두 시드
각각에서도 (+0.113 / +0.159) 모두 양이고 잡음 폭을 넘는다.

⚠️ 그러나 **"+0.136 = 필터뱅크 초기화의 효과" 는 아니다.** D-1 은 ④ 대비 네
가지가 다르다 — 초기화 / 첫 층 활성화 `Abs` / LR 0.0003 / ft 스케줄.
지금 돌리는 **④-ft**(LR·스케줄만 바꾼 대조군)가 있어야 갈린다:

    D-1 − ④-ft  =  필터뱅크 초기화 + Abs 의 효과
    B   − ④-ft  =  KWS20 사전학습 + bias 의 효과

## 3. 관찰 — D-1 의 시드 간 차이가 작았다 (원인 미확정)

D-1 의 두 시드가 300/h 에서 0.007, 1000/h 에서 0.000 차이였다. 같은 조건의 ④가
0.052 / 0.077 흔들린 것과 대비된다.

⚠️ **이것을 "필터뱅크가 분산을 줄인다" 로 쓰지 않는다.** 두 가지 이유다.
1. **시드 2개로는 분산을 말할 수 없다.** 두 값이 우연히 가까울 수 있다
2. **원인이 분리되지 않는다.** D-1 은 LR 도 0.0003 으로 낮다(④는 0.001).
   안정성이 초기화 때문인지 낮은 LR 때문인지 구분할 수 없다

→ **"관찰됨, 원인 미확정"** 으로 기록한다. ④-ft(LR 0.0003, 무작위 초기화)의 두
시드가 나오면 갈린다 — ④-ft 도 안정적이면 LR 탓이고, ④-ft 가 흔들리면 초기화
쪽이다. 분산을 주장하려면 그 뒤에도 시드를 3개 이상으로 늘려야 한다.
