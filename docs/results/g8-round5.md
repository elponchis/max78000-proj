## 2. 해상도 가설 — **기각**

첫 층 커널 k 를 1→2→4 로 늘리면 FIR 이 128→256→512탭이 되고 분해능이
500→250→125Hz 가 된다. **k=4 는 ① 멜의 `n_fft=512` 와 창 길이가 정확히 같다.**

| | macro-F1 @300/h | @1000/h | conv1 가중치 | 분해능 |
|---|---:|---:|---:|---:|
| k=1 | **0.4982** | **0.6305** | 12,800 B | 500Hz |
| k=2 | 0.4844 | 0.6241 | 25,600 B | 250Hz |
| k=4 | 0.4871 | 0.6216 | 51,200 B | 125Hz |

- 단조 추세가 **없고**, 셋 다 시드 잡음(0.052) 안이다.
- 학습 전 톤 검산에서 해상도가 실제로 개선됨을 확인했다 — 125Hz 톤의 인접
  밴드 분리도가 1.0 → 2.1 → **9.5dB**, 1000Hz 에서 1.5 → 6.5 → **36.8dB**,
  k=4 는 미분리 밴드 0개 (`g8-d1-filterbank.md` 부록 A.4).
  **초기화가 잘못 들어가서 안 오른 것이 아니다.**
- 파라미터는 165,457 → 178,257 → 203,857 (442KB 대비 36.6 → 39.4 → 45.0%).
  **7.7%·23.2% 를 더 쓰고 얻은 것이 없다.**

→ ①−④ 격차의 원인은 **주파수 해상도가 아니다.** 다음 가설은 로그 압축
(`config1-lin-design.md`, 학습 진행 중).

## 3. 제곱근 역빈도 가중치 — 지금까지 최고, 다만 단일 시드

D-1 과 **손실 가중치 하나만** 다르다 (`class_weights(power=0.5)`).
background 0.272 → 0.637, 이벤트 클래스는 절반 수준으로.

| | @300/h | @1000/h | siren | glass | scream | dog_bark | argmax 오경보/h |
|---|---:|---:|---:|---:|---:|---:|---:|
| D-1 | 0.4982 | 0.6305 | 26.5% | 25.3% | 28.0% | 31.6% | 4,382 |
| **D-1(√)** | **0.5209** | **0.6594** | 21.8% | 28.1% | 27.1% | **43.8%** | **2,885** |
| 차이 | **+0.0227** | **+0.0289** | −4.7pp | +2.8pp | −0.9pp | **+12.2pp** | −34% |

**기대한 방향과 맞는다.** 배경음을 2.3배 더 배우니 argmax 오경보가 34% 줄었고,
**고정 오경보 지점에서도** macro-F1 이 올랐다 — 단순한 동작점 이동이 아니다.
이득은 거의 전부 `dog_bark`(+12.2pp)에서 나왔고 `siren` 은 오히려 −4.7pp 다.
`siren` 은 고유 원본이 202개뿐이라(CLAUDE.md 4장) 가중치를 낮추면 가장 먼저
손해를 보는 클래스라는 설명과 일관된다.

⚠️ **단일 시드이고 +0.0227 은 시드 잡음(0.052)보다 작다.** 방향은 예측과
맞지만 **아직 결론이 아니다.** 시드 2·3 이 필요하다 (실행당 약 25분).

## 5. 부수 발견 — OpenBLAS 소행렬 오버헤드 (67배)

멜 계열을 CPU 에서 돌리려다 배치당 5.6초가 나왔다(1D 는 0.11초). 원인은 2D
모델이 아니라 **멜 필터뱅크 행렬곱 하나**였다.

```
(64,257) @ (257,64)  =  2 MFLOP
  기본                       23.8 ms
  OPENBLAS_NUM_THREADS=1      0.148 ms   ← 160배, 결과는 비트 단위로 동일
```

`mel_int8()` 전체가 41.5ms → **0.616ms**, 학습 배치가 5.6s → **0.34s**.
`melfeat.py` 의 "창당 약 1ms" 주석은 틀리지 않았고 환경이 문제였다.
상세는 CLAUDE.md 12장. 노트북 멜 셀 5개와 `run_chain6.sh` 에 반영했다.

→ 이 덕분에 **2D 실험도 WSL CPU 에서 돌릴 수 있게 됐다** (실행당 81분).
Colab GPU 가 소진돼도 진행이 막히지 않는다.

## 6. 실수 기록

1. **진입점을 `models` 리스트에 등록하지 않아** 첫 체인이
   `train.py: error: argument --model: invalid choice` 로 즉사했다.
   진입점/train.py 인자 규약 불일치로 죽은 것이 네 번째라
   `tools/kat_entrypoints.py` 에 등록 여부 검사를 넣었다.
2. **`cmp_all.sh` 의 `ls -d | head -1`** 이 이름 순 첫 번째를 집어, 위 1번으로
   죽은 빈 폴더를 골랐다 → D-1(√)가 표에서 통째로 빠졌다. `ls -dt` 로 고쳤다.
3. **`run_chain6.sh` 의 속도 게이트가 잘못된 CWD 에서 돌아** argparse 오류로
   4초 만에 죽었고, 게이트는 그걸 "150에폭 3분" 으로 읽어 통과시켰다.
   `cd` 를 앞으로 옮기고 종료 코드를 보도록 고쳤다 — **게이트가 실패를
   통과로 읽으면 게이트가 아니다.**
4. `kat_melcomp.py` 에서 `ai8x.normalize` 를 역산해 통계를 냈다가 평균
   −231.9(int8 범위 밖)가 나왔다. `normalize` 는 `act_mode_8bit` 에 따라
   아핀이 달라진다(`ai8x.py:36`). 변환 전 원본 int8 을 직접 보도록 고쳤다.
