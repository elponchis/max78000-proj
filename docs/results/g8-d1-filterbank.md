150에폭 22분 (에폭당 6~8초). 단일 시드 예비 결과다 — 4장을 읽지 않고 인용하지 말 것.

설정: `ai85safesoundnet_fb` (첫 층 활성화 `Abs`), 멜 대역통과 FIR 50밴드 초기화,

## 2. **B 가 못 바꾼 것을 바꿨다** — 배경음 거부 능력

배경음 출처별 `→siren` 비율 (argmax):

| 출처 | 창 | ④·B | **D-1** | ① |
|---|---:|---:|---:|---:|
| 일반 배경음 | 1,654 | 10~55% | **4.5%** | 1~3% |
| 하드네거티브:alarm | 1,005 | 10~55% | **8.2%** | 1~3% |
| 하드네거티브:glass_dishes | 290 | 10~55% | **1.4%** | 1~3% |
| 하드네거티브:scream_crowd | 201 | 10~55% | 17.9% | 1~3% |
| 하드네거티브:glass_ring | 25 | — | 4.0% | 1~3% |
| 하드네거티브:baby_cry | 79 | — | 6.3% | 1~3% |

주요 출처(일반·alarm·glass_dishes)가 **①에 근접한 한 자릿수**로 내려왔다.
B 는 이 수치를 거의 바꾸지 못했다(`g8-b-kws20init.md` 3장) — 즉 **사전학습은
못 옮긴 "배경음 거부 능력" 을 필터뱅크 초기화는 일부 옮겼다.**

해석: 첫 층이 대역통과 필터뱅크로 출발하면 이후 층이 **주파수 구조 위에서**
판별을 배운다. 배경음을 거부하는 능력은 "어떤 주파수 패턴이 사이렌이 아닌가" 를
아는 것이고, 그것은 시간축 원시 파형보다 주파수 표현에서 배우기 쉽다. ①의 강점이
표현에서 온다는 가설과 방향이 같다.

⚠️ 창 수가 적은 행은 잡음이다 — `glass_ring [조용]` 8창 50%, `glass_dishes
[조용]` 48창 25% 는 표본이 모자라 해석하지 않는다.

## 3. D-1 vs B 는 **깨끗한 비교다**

둘 다 LR 0.0003 + `schedule_safesound_ft.yaml` + `--exp-load-weights-from` 이다.
다른 것은 **무엇으로 초기화했는가**뿐이다 (bias 는 B 만 True).

    D-1 0.498  −  B 0.457  =  **+0.041**  ← 초기화 방식의 차이

→ 같은 파인튜닝 설정에서 **멜 필터뱅크 초기화가 KWS20 사전학습보다 낫다.**
음성 21단어로 배운 시간축 필터보다, 주파수 대역을 명시적으로 심는 것이 환경음에
더 맞는다는 뜻이다. (단일 시드라는 한계는 4장.)

## 4. 한계

1. **CPU 학습이다.** 같은 시드·같은 인자라도 **장치 간 결과가 비트 단위로 같지
   않다.** `--deterministic` 은 장치 간 동일성을 보장하는 옵션이 아니다 (cuDNN
   커널 선택, 부동소수점 누적 순서, atomicAdd 비결정성은 GPU 쪽에만 있다).
   → **다른 구성과 소수점 단위로 비교하지 않는다.** 결론이 D-1 에 걸리면 GPU
   복구 후 같은 설정으로 재학습해 확인한다. `g8-first-comparison.md` 4.3.1
2. **단일 시드.** +0.111 이 잡음 안인지 모른다. 기준선의 시드 간 분산을 아직
   재지 않았다 → **④ 시드 2 가 다음 작업**이다
3. **D-1 은 ④ 대비 세 가지가 다르다** — 초기화 / 첫 층 활성화 `Abs` / LR·스케줄.
   `Abs` 는 초기화와 떼어 낼 수 없다(밴드당 2필터로 크기를 얻으려면 필요하다).
   LR·스케줄만 바꾼 ④ 대조가 있으면 나머지를 가를 수 있다 (셀 19 에서 1회).
   ⚠️ 따라서 "필터뱅크 초기화의 효과 = +0.111" 이라고 적으면 **틀린 서술**이다.
   B 와의 비교(+0.041)만이 초기화 방식을 분리한다
4. **500Hz 아래 9개 밴드는 초기화 시점에 서로 분리되지 않았다** (128탭의 분해능이
   약 500Hz). 학습이 갈랐는지는 확인하지 않았다 — 학습 후 `voice_conv1` 가중치의
   주파수 응답을 그려 보면 알 수 있다 (향후)
5. **학습 가능 판만 돌렸다.** 고정(`FREEZE=True`) 판은 "고정 필터뱅크 자체가
   도움이 되는가" 에 답하는 두 번째 실험이다 — 학습 가능 판이 효과를 보였으므로
   이제 돌릴 값어치가 생겼다
