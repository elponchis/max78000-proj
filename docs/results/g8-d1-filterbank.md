## 2. **B 가 못 바꾼 것을 바꿨다** — 배경음 거부 능력

배경음 출처별 `→siren` 비율 (argmax):

| 출처 | 창 | ④·B | **D-1** | ① |
|---|---:|---:|---:|---:|
| 일반 배경음 | 1,654 | 10~55% | **4.5%** | 1~3% |
| 하드네거티브:alarm | 1,005 | 10~55% | **8.2%** | 1~3% |
| 하드네거티브:glass_dishes | 290 | 10~55% | **1.4%** | 1~3% |
| 하드네거티브:scream_crowd | 201 | 10~55% | 17.9% | 1~3% |
| 하드네거티브:glass_ring | 25 | — | 4.0% | 1~3% |
| 하드네거티브:baby_cry | 79 | — | 6.3% | 1~3% |

주요 출처(일반·alarm·glass_dishes)가 **①에 근접한 한 자릿수**로 내려왔다.
B 는 이 수치를 거의 바꾸지 못했다(`g8-b-kws20init.md` 3장) — 즉 **사전학습은
못 옮긴 "배경음 거부 능력" 을 필터뱅크 초기화는 일부 옮겼다.**

해석: 첫 층이 대역통과 필터뱅크로 출발하면 이후 층이 **주파수 구조 위에서**
판별을 배운다. 배경음을 거부하는 능력은 "어떤 주파수 패턴이 사이렌이 아닌가" 를
아는 것이고, 그것은 시간축 원시 파형보다 주파수 표현에서 배우기 쉽다. ①의 강점이
표현에서 온다는 가설과 방향이 같다.

⚠️ 창 수가 적은 행은 잡음이다 — `glass_ring [조용]` 8창 50%, `glass_dishes
[조용]` 48창 25% 는 표본이 모자라 해석하지 않는다.

## 3. D-1 vs B — LR·스케줄은 같지만 **초기화만 다른 것은 아니다**

⚠️ 앞서 이 비교를 "초기화만 다르다" 고 적었는데 **틀렸다. 세 가지가 다르다.**

| | B kws20(ft) | D-1 fb(abs) |
|---|---|---|
| 초기화 | KWS20 v3 사전학습 (conv 8층) | 멜 대역통과 FIR 50밴드 (첫 층만) |
| **첫 층 활성화** | ReLU (기준선과 같다) | **`Abs`** |
| **bias** | **True** (체크포인트의 conv bias 를 받기 위해) | False (기준선과 같다) |
| LR / 스케줄 | 0.0003 / `..._ft.yaml` | 0.0003 / `..._ft.yaml` ← 같다 |

같은 것은 LR·스케줄·에폭·QAT 시점이고, 다른 것은
**초기화 방식 + 첫 층 활성화 + bias** 다.

    D-1 0.498  −  B 0.457  =  +0.041

**이 +0.041 을 결론으로 쓰지 않는다.** 이유 둘.
1. 위 표대로 세 가지가 함께 다르므로 "초기화 방식의 차이" 로 귀속할 수 없다
2. **시드 잡음과 장치 차이의 크기를 아직 모른다.** D-1 은 CPU, B 는 GPU 학습이고
   양쪽 다 단일 시드다. +0.041 이 그 변동 안일 수 있다

→ 지금 측정 중인 것이 정확히 그 눈금이다 (`TASKS.md`):
`④ 시드 1 CPU`(GPU 판과 비교 → **장치 차이**), `④ 시드 2 CPU`(→ **시드 잡음**),
`D-1 시드 2 CPU`. 세 값이 나온 뒤에 +0.041 과 +0.111 을 해석한다.

## 4. 한계

1. ~~CPU 학습이라 소수점 비교 금지~~ → **측정으로 해소됐다** (2026-09-27 저녁,
   `g8-noise-scale.md`). ④ 시드 1 의 CPU/GPU 차이가 300/h 에서 **0.002** 로,
   같은 모델의 시드 간 차이 0.052 의 약 1/25 였다. 장치 차이는 측정 가능한 수준
   아래이므로 CPU 결과를 GPU 결과와 같은 표에 놓아도 된다.
   (1000/h 에서는 +0.016 으로 조금 크다 — 정확히 0 이라고 주장하지는 않는다.)
2. **시드 잡음이 측정됐다: ④ 300/h 에서 0.052, 1000/h 에서 0.077.**
   D-1 은 시드 2 도 돌렸고(0.4917), **시드 평균 대비 시드 평균으로 +0.136** 이다
   — 잡음 폭의 약 2.6배이므로 **향상은 잡음보다 크다**.
   ⚠️ 시드 2개는 분산 추정이 아니라 "적어도 이만큼 흔들린다" 는 하한이다.
3. **D-1 은 ④ 대비 세 가지가 다르다** — 초기화 / 첫 층 활성화 `Abs` / LR·스케줄.
   `Abs` 는 초기화와 떼어 낼 수 없다(밴드당 2필터로 크기를 얻으려면 필요하다).
   LR·스케줄만 바꾼 ④ 대조가 있으면 나머지를 가를 수 있다 (셀 19 에서 1회).
   ⚠️ 따라서 "필터뱅크 초기화의 효과 = +0.111" 이라고 적으면 **틀린 서술**이다.
   **B 와의 비교(+0.041)도 초기화를 분리하지 못한다** — 3장 표대로 활성화와
   bias 도 함께 다르다. 어떤 수치도 아직 "초기화의 효과" 가 아니다
4. **500Hz 아래 9개 밴드는 초기화 시점에 서로 분리되지 않았다** (128탭의 분해능이
   약 500Hz). 학습이 갈랐는지는 확인하지 않았다 — 학습 후 `voice_conv1` 가중치의
   주파수 응답을 그려 보면 알 수 있다 (향후)
5. **학습 가능 판만 돌렸다.** 고정(`FREEZE=True`) 판은 "고정 필터뱅크 자체가
   도움이 되는가" 에 답하는 두 번째 실험이다 — 학습 가능 판이 효과를 보였으므로
   이제 돌릴 값어치가 생겼다
