## 2. 첫 실패(C)의 원인은 찾았고 고쳤다 — 그런데 결과는 나아지지 않았다

**진단**: ① 로짓이 |값| 평균 1435 규모라(QAT 체크포인트를 `act_mode_8bit` 없이
추론하면 `output_shift` 스케일링이 빠진다) **T=4 에서 최대확률 0.998** —
소프트 타깃이 사실상 one-hot 이었다. 증류가 "교사의 하드 라벨" 을 주었고
`distill_wt 0.7` 로 손실의 70%를 차지해, 교사가 틀린 약 11% 창에서 확신에 찬
오답을 강요했다.

**수정**: 학습셋 13,007창에서 전역 상수 **s = 202.8** 을 구해 교사 로짓을 나눴다
(`tools/calib_teacher.py`). ⚠️ 샘플별이 아니라 **전역 상수 하나**다 — 샘플 간
확신도 차이가 증류가 전달하려는 정보의 핵심이라 샘플마다 정규화하면 그것을 지운다.
수정 후 T=4 에서 유효 클래스 **1.01 → 2.89** (1.0=one-hot, 5.0=균등).

**결과**: 300/h 에서 0.3335 → **0.3114 로 오히려 더 나빠졌다.**

→ **one-hot 은 원인의 전부가 아니었다.** 진단은 검증 가능했고 실제로 고쳐졌지만
(유효 클래스가 증거다) 성능은 따라오지 않았다.

## 3. 표현 능력 가설 — **미검증**

지금 더 설득력 있는 설명은 이것이다.

> 증류는 교사의 **입력 → 출력 함수**를 학생에게 옮긴다. 그런데 교사와 학생은
> **서로 다른 입력 표현**을 본다(로그 멜 vs raw 파형). 학생이 그 함수를 표현할
> 능력 자체가 부족하면 — ④가 ①보다 나쁜 이유가 정확히 그것이다 — 표현할 수 없는
> 함수를 억지로 맞추게 하는 것이 **라벨을 직접 맞추는 것보다 나쁠 수 있다.**

이 가설은 D-1+C′ 와 C′ 의 대비와 맞는다. 같은 교사·온도·가중치인데

- **④ 위에서는 해롭다** (−0.074): raw 파형 학생이 멜 교사의 경계를 못 받아들인다
- **D-1 위에서는 무해하다** (−0.006): 필터뱅크로 출발한 학생은 주파수 구조 위에서
  동작하므로 어느 정도 받아들인다

D-1+C′ 의 내부 구성이 바뀐 것도 같은 방향이다 — `siren` 26.5 → **34.0%** 로 오르고
`dog_bark` 31.6 → 25.5% 로 내려, macro-F1 은 상쇄돼 제자리지만 **증류가 아무 영향도
주지 않은 것은 아니다.**

⚠️ **가설이고 검증하지 않았다.** 검증하려면 예컨대 ① 을 교사로 ① 을 학생으로 두는
대조(같은 표현끼리의 증류)가 필요한데, 그것은 G8 의 질문이 아니다.
⚠️ 시드 1개씩이다. D-1+C′ 의 −0.006 은 잡음(0.052) 한참 안이라 **"무해하다"**
까지가 말할 수 있는 전부이고 "증류가 D-1 에 도움이 된다" 는 아니다.

## 4. 접는 이유

1. 두 번의 실패(−0.074, −0.052)와 한 번의 무해(−0.006). **어느 설정에서도
   개선이 없었다**
2. 원인으로 짚인 것(표현 능력 불일치)이 맞다면 하이퍼파라미터로 고칠 수 있는
   문제가 아니다 — 교사·학생의 표현이 다른 것이 전제이기 때문이다
3. 남은 질문(표현 vs 구조)에는 **wave2D 가 직접 답한다.** 같은 학습 1회로
   G8 의 주장을 성립시키는 값이 더 크다

→ 증류는 **여기서 멈추고** 결과를 그대로 기록한다. 논문에는 "시도했고 이 설정에서
듣지 않았다" 로 적는다. 구현(`AI85SafeSoundMelTeacher`, `wrap_teacher.py`,
`calib_teacher.py`, `kat_teacher.py`)은 남겨 둔다 — 재개 비용이 낮고, 교사 어댑터
자체가 "서로 다른 입력 표현 사이의 증류" 를 다루는 방법으로서 기록할 값어치가 있다.

## 5. 얻은 검사 둘 (이것이 실질적 수확이다)

1. **`kat_teacher.py` 의 첨예도 검사** — 학습 온도에서 **유효 클래스 수
   (exp(엔트로피)) ≥ 1.5**. 교사↔① 일치만 보고 이것을 빠뜨려 C 를 한 번 버렸다.
   ⚠️ 실패 시 `--kd-distill-wt` 를 낮추는 것으로 고치지 말 것 — one-hot 인 채로
   비중만 줄이면 원리적으로 증류가 아니다
2. **`compare_runs.py` 의 완료 검사** — QAT 는 에폭 60부터라 `qat_best` 가 학습
   도중에도 생긴다. D-1+C′ 를 83/150 에폭 시점에 재서 **0.4426 으로 잘못 보고**
   했고 완료 후 값은 **0.4927** 이었다. 이제 로그에 최종 테스트 단계가 없는 실행은
   기본적으로 제외한다 (`--allow-incomplete` 로 덮어쓸 수 있다)
