# 에너지 추정 — 실측 지연 × 공개 전력 (2026-10-02 방침 확정)

> ## ⚠️ 이 문서의 에너지 값은 전부 **추정(실측 지연 × 공개 전력)** 이다.
> **직접 에너지 계측은 하지 않았다.** 문서·논문 초안 어디에도 "측정" 으로
> 쓰지 않는다. 논문 한계 절에 "직접 에너지 계측 미수행, 향후 과제" 를 적는다.

## 1. 방법

구성별 판단 1회 에너지를 구간 합으로 추정한다.

```
E = Σ ( 구간별 실측 시간 × 그 구간 모드의 전력 )
```

| 구간 | 모드 | 시간 출처 |
|---|---|---|
| 입력 적재 | CPU 활성 (CNN 켜짐·대기) | 보드 실측 (SysTick, POR 직후, 1000회) |
| 추론 | NPU 동작 + CPU 바쁜 대기 | 〃 |
| 전처리 (구성 ① 만) | CPU 활성 | 〃 (C 구현 후) |
| 출력 (unload + softmax) | CPU 활성 | 〃 |
| M4 소프트웨어 추론 (대조군) | CPU 활성, NPU 꺼짐 | 〃 (구현 후) |

전력은 **출처 2종을 나란히** 쓰고 두 값의 **범위**를 보고한다.
- **(가) 데이터시트** — MAX78000 Electrical Characteristics (문서명·페이지·조건 인용)
- **(나) 동일 칩 실측 선행연구** — 보고된 에너지·시간에서 역산한 평균 전력

## 2. 가정 표 (논문에 그대로 싣는다)

| 항목 | 값 | 근거 |
|---|---|---|
| 코어 클럭 | 100 MHz (IPO) | 펌웨어 시리얼 `SystemCoreClock 100000000 Hz` |
| CNN 클럭 | 50 MHz (PCLK ÷ 1) | `cnn_enable(PCLK, DIV1)` |
| 공급 전압 | 출처별로 다르다 — 아래 3절 | (가) 는 레일별 전압, (나) 는 각 논문의 공급 조건 |
| 추론 대기 | **바쁜 대기** (슬립 아님) | `while (cnn_time == 0) {}` |
| 슬립·유휴 구간 | **포함하지 않는다** | 판단 1회의 능동 구간만. hop 250 ms 의 나머지는 계산에 없다 |
| 가중치 적재 | 포함하지 않는다 | 부팅 시 1회 (상시 동작에서 반복되지 않는다) |
| 마이크·코덱·PMIC·LED | 포함하지 않는다 | 칩 전력만. 보드 수준 전력이 아니다 |

## 4. 구성 ④ — 1차 추정 ((나) 출처만)

시간은 `docs/results/synthesis-check.md` 8절 (POR 직후, 1000회 최악):
적재 1.087 ms / 추론 1.439 ms / 출력 0.008 ms.

| 추론 전력 출처 | 추론 구간 | CPU 구간 (적재+출력, 24.8 mW 가정) | **합계 (추정)** |
|---|---:|---:|---:|
| Moosmann 35.6 mW | 51 µJ | 27 µJ | **약 78 µJ** |
| Ulkar & Okman 71.7 mW | 103 µJ | 27 µJ | **약 130 µJ** |
| Moss 피크 89 mW (상한) | 128 µJ | 27 µJ | **약 155 µJ** |

→ **④ 판단 1회 약 78~155 µJ — 추정(실측 지연 × 공개 전력).**
CPU 구간 전력은 Moss 의 "CNN 켜짐" 전류(7.5 mA × 3.3 V)를 썼다 — 다른
출처에는 CPU 구간 전력이 없다.
