# 비명(scream) 재현율 개선 — 설계안 (2026-10-13, **실행 전**)

사용자 지시(2026-10-13): 현황을 표로 적고, 후보 세 가지를 작업량·예상 효과·"외부 세트를 보고 조정하는 일이
되는지" 로 비교하며, 청취가 필요하면 몇 창을 들어야 하는지 계산한다. **청취 세트는 만들지 않고, 학습·전처리도
돌리지 않는다.** 이 문서는 설계안이며 어느 후보도 채택된 것이 아니다. 채택하면 `v4-distill-design.md` 식으로
사전 등록(판정 지표·조건)을 먼저 쓴다.

관련: 비명 하락 자체는 본 표의 한계로만 적고 원인 조사는 하지 않기로 했다 (`STATUS.md` ★ 표 v4+D 한계,
2026-10-11). 이 문서는 그 결정을 바꾸지 않는다 — "다음에 한다면 무엇을" 의 설계다.

못하고, 정의를 어디에 긋느냐의 문제다.

## 3. 후보 세 가지

### (1) 학습 비명 창을 청취로 검증해 틀린 창을 제외

- **무엇**: 학습 비명 559 창(또는 의심 구간)을 듣고 X 창을 학습에서 뺀다 (`data_overrides.csv` drop). 시험셋
  비명도 같은 기준으로 들어 X·? 를 채점에서 제외하면 testL 처럼 **정답이 바뀐다** — 모델 개선과 정답 변경이
  섞이므로, 시험셋 청취는 별도 항목으로 사전 등록하고 두 효과를 나눠 보고한다.
- **청취 창 수**: 4절. 전수 559 (+ 시험셋 225 = 784), 층화 최소안 314 창.
- **학습 횟수**: 간격 400·④ × 3시드 = **6회** (v4+D 설정; 약 60·57 분/실행 → 약 6 시간) + `eval_v4.py` 재채점.
  PANNs 교사 캐시·AudioSet U 는 그대로 (라벨 창만 빠진다).
- **예상 효과**: **작을 가능성이 높다.** 의심 구간(Yell·Shout 만 90 + AudioSet 124 = 214 창, 38%)의 절반이
  빠진다고 해도 Screaming 보유 창 345 는 그대로이고, 시험셋 비명 재현율의 바닥은 라벨이 아니라 경계 모호성
  (7.1)과 외부 분포 차이다. 다만 **"학습 라벨 탓이 아니다" 를 확정**해 주므로 (2)·(3) 의 근거가 된다.
- **외부 세트를 보고 조정하는가**: **아니다** — 청취 대상은 학습·시험 창이고 외부는 채점만. 가설이 외부 청취
  결과(Yell·Shout 만 55% X)에서 왔다는 점은 밝힌다. 외부 수치로 효과를 **확인**하는 것은 테스트 전용 규칙 안이다.

### (2) 비명과 고함(`Yell`·`Shout`)의 정의 재검토

- **무엇**: 판정 순서의 `scream` 을 **`Screaming` 보유 클립만**으로 좁히고, `Yell`·`Shout` 만 보유한 클립은
  (2a) 배경 하드 네거티브 그룹 `shout` 로 보내거나 (2b) 폐기한다. 2a 가 규칙 3-1(배제분은 하드 네거티브)과
  맞는다. 외부 세트 정의 real31(`Screaming` 보유)과도 같아진다.
- **작업량**: 매니페스트·전처리 재생성 (`build_class_manifest.py` → `prepare_safesound.py`, 비명·배경 셰드만
  다시; 수 시간), 교사 캐시 재생성(라벨 창 교사 출력), 학습 **6회** (간격 400·④ × 3), 재채점. **시험셋 비명이
  225 → 159 창으로 줄어 정답이 바뀌므로** 부록 표(v1·v2.1·v3.1·v4)도 같은 정답으로 다시 채점해야 한 표에
  섞이지 않는다 (`eval_v4.py` 캐시로 수 분). 근거를 세우려면 Yell·Shout 만 창 **156 창 (학습 90 + 시험 66)**
  청취가 필요하다 — 규칙만 바꾸면 "외부에서 봤다" 가 유일한 근거가 된다 (아래).
- **예상 효과**: **세 후보 중 가장 크다, 그러나 절반은 정의 효과다.** 외부 Yell·Shout 만 창의 55% 가 비명이
  아니었고 PANNs 도 real31 50.0% 대 v1eq 23.5% 로 갈린다 (`label-audit.md`). 학습에서 고함을 배경으로 보내면
  "고함 ≠ 비명" 을 배우므로 환호·고함 오탐이 줄고, 시험셋 재현율은 Yell·Shout 만 66 창이 빠져 **정의상** 오른다.
  실사용 비명(real31L) 재현율이 오르는지는 별개이고, 그것만이 모델 개선의 증거다. 논문 한계 1(비명↔환호)은
  그대로 남는다 — 선을 `Screaming` 라벨로 옮긴 것뿐이다.
- **외부 세트를 보고 조정하는가**: **부분적으로 그렇다.** 정의를 바꾸는 근거가 외부 청취 결과라면 설계 결정을
  외부로 내리는 셈이다. 완화: 결정 근거를 **학습·시험의 Yell·Shout 만 156 창 청취**로 다시 세우고 (기준 예:
  X 비율 ≥ 50% 면 정의 변경), 외부는 채점만 한다. 기준·순서를 청취 전에 사전 등록한다.

### (3) 비명만 별도 문턱값

- **무엇**: 지금은 단일 마진 문턱값(`max 이벤트 로짓 − 배경 로짓 > thr`, 시험셋 배경 @300/h) 이다
  (`tools/eval_threshold.py`). 비명 마진에 **별도 문턱값** `thr_scream` 을 두고 나머지 클래스는 `thr` 를 쓴다.
  총 오경보를 300회/h 로 유지하려면 배분이 필요하다 (예: 비명 100/h + 나머지 200/h; 또는 비명 문턱값은
  "비명 오경보만 N/h" 로 따로). **배분 규칙을 사전 등록**하고 시험셋 배경에서만 정한다.
- **작업량**: 학습 **0회**. 채점 코드에 클래스별 문턱값(`thr_at` → 클래스별 마진 분위수) 추가 + 전 구성 재채점
  (로짓 캐시, 수 분). 펌웨어는 문턱값 상수 2개 — 지연·에너지 변화 없음. 설계 단계에서 먼저 할 일: **시험셋
  testL 로짓만으로** "비명 오경보 배분 x/h 대 비명 재현율·다른 클래스 재현율" 곡선을 그려 효과를 본다 (외부
  로짓은 보지 않는다).
- **예상 효과**: 비명 재현율은 오르고 다른 클래스 재현율이 내리거나(배분) 총 오경보가 는다. macro-F1 은 미지수,
  **mAP 는 변하지 않는다** (문턱값 무관). PANNs 가 외부 @300/h 지점에서 62.3% 인데 시험셋 문턱값으로 37.7% 인
  것처럼, 외부 비명의 상당수는 "마진이 모자라서" 놓치므로 (3) 이 가장 싸게 외부 비명을 건진다. 단, 비명 문턱값을
  낮추면 환호·고함 오탐(하드 네거티브 `scream_crowd` 자체 오탐률 73%)이 먼저 는다 — 그래서 배분이 필요하다.
- **외부 세트를 보고 조정하는가**: **아니다, 시험셋 배경에서만 정하면.** 배분이나 문턱값을 외부 결과를 보며
  고르는 순간 조정이 된다 — 금지. 외부는 사전 등록한 배분으로 한 번 채점한다.

## 4. 청취 창 수 계산

목적은 "학습 비명 창의 오류율 p" 를 추정해 제외 기준을 세우는 것이다. 95% 신뢰구간 반폭 E 로 p 를 추정하려면
n = 1.96² · p(1−p) / E² (단순 무작위, 유한 모집단 보정 전).

| 가정 p | E = ±5 pp | E = ±7.5 pp | E = ±10 pp |
|---|---:|---:|---:|
| 0.18 (외부 Screaming 보유 창의 X 비율) | 227 | 101 | 57 |
| 0.34 (외부 전체 X 비율) | 345 | 153 | 86 |
| 0.50 (최악) | 384 | 171 | 96 |

- 모집단이 559 라 ±5 pp 에 345~384 창이면 **전수(559)의 62~69%** 다 → 무작위 표본보다 **전수 청취**가 낫다
  (유한 모집단 보정을 해도 ±5 pp 에 약 240~270 창). 1창 약 5~8초 × 559 ≈ 50~75 분 (청취 1회 기준, 이전 470창
  청취와 같은 속도).
- **층화 최소안 314 창**: 의심 구간 전수 — Yell·Shout 만 90 + AudioSet 124 = 214 창 — 에 Screaming 만 315 창 중
  무작위 100 (p=0.18 가정 ±7.5 pp). (2) 의 근거를 겸하려면 시험셋 Yell·Shout 만 66 창을 더해 **380 창**.
- 판정자는 1인(저자)이고 일치도는 재지 않는다 (논문 한계 2) — 외부 청취 때처럼 대조 창(PANNs ≥ 0.50 학습 창
  15개)을 섞어 일관성만 본다.
- **청취 세트는 만들지 않았다.** 만들 때는 `tools/label_audit.py` 의 외부 비명 세트와 같은 형식(창 ID·시작 샘플만,
  모델 출력·PANNs 점수 비노출, 무작위 순서)으로 하고, 판정 기준(O/X/?)과 제외 규칙을 먼저 쓴다.

## 5. 이 문서가 바꾸지 않는 것

- 본 표(v4+D)·정답(testL / real31L)·사전 등록된 판정. 외부 세트는 테스트 전용 그대로.
- 비명 하락을 한계로만 적는 결정 — 이 설계안을 실행하기로 하면 그때 한계 절을 고친다.
- 증강은 바꾸지 않는다. AudioSet 추가 수집은 하지 않는다.
