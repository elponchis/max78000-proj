## 2. argmax 개선은 과장이다 — 고정 오경보에서 줄어든다

argmax 기준으로 보면 `glass` 82.8% 같은 큰 숫자가 나온다. 그러나 그것은
**이벤트 쪽으로 기울어진 동작점의 결과**이고, 오경보를 같은 값으로 고정하면
개선폭이 줄어든다.

- argmax 는 각 모델이 알아서 정한 동작점이다. 배경음을 더 버린 모델이 이벤트
  재현율만 높게 보인다 (`eval_confusion.fixed_fa_points` 의 설명)
- B 는 사전학습 + 파인튜닝 설정으로 **이벤트 쪽 기울기가 더 커진 모델**이다.
  그래서 argmax 에서 특히 좋게 보이고, 300/h 로 묶으면 +0.070 으로 줄어든다
- → **논문·보고에는 고정 오경보 수치만 쓴다.** argmax 숫자는 참고로만 적고
  반드시 "동작점이 다르다" 는 단서를 붙인다

## 3. 더 중요한 발견 — ④의 약점은 알람↔사이렌이 아니라 **배경음 거부 능력 전반**이다

배경음 출처별 `→siren` 비율:

| | ④ wave | B kws20(ft) | ① mel |
|---|---:|---:|---:|
| 모든 출처 (일반·alarm·glass_dishes·scream_crowd·baby_cry·glass_ring) | 10~55% | 10~55% | **1~3%** |

①은 **출처를 가리지 않고** 1~3% 다. 사전학습(B)은 이 수치를 거의 바꾸지 못했다.

→ 2026-09-27 청취에서 세운 가설("알람은 고정 음높이, 사이렌은 휘는 음높이 →
스펙트로그램이 유리")은 **너무 좁았다.** ①의 강점은 특정 혼동 하나를 잘 가르는
것이 아니라, **배경음 전반을 `siren` 으로 오인하지 않는 능력**이다. raw 파형
모델은 그 능력 자체가 약하고, 사전학습으로 채워지지 않는다.

→ **이 발견이 C(지식 증류)의 우선순위를 올린 근거다.** 증류는 교사의 **결정
경계 전체**를 전달하므로 "배경음을 거부하는 방식" 을 직접 옮긴다. 초기화는
출발점만 바꾸고 그 능력은 옮기지 못한다 (실측으로 확인됐다).

## 4. 한계

1. **단일 시드.** +0.070 이 잡음인지 모른다 → ④ 시드 2 가 다음 작업이다
2. **B 는 초기화 외에 세 가지가 더 다르다** — LR 0.0003(기준선 0.001),
   파인튜닝 스케줄(첫 감쇠 40 vs 75), `bias=True`. 그래서 이 +0.070 을
   "사전학습 초기화의 효과" 라고 적으면 **틀린 서술**이다. 분해하려면 LR·스케줄만
   바꾼 ④ 대조가 하나 더 필요하다 (셀 19 에서 돌릴 수 있다)
3. **입력 스케일 불일치가 남아 있다.** `kws20.py:392` 가 파일 단위 피크 정규화를
   하고 우리는 하지 않는다 (CLAUDE.md 7장). epoch 30 중단 기준(48.23%)은
   통과했으므로 치명적이지는 않았지만, 사전학습 특징이 온전히 전이됐다고 볼
   근거도 없다 — `siren` 하락이 이것과 관련될 수 있다
4. **창 단위·이 테스트셋 구성 의존** (배경음의 49.9%가 하드 네거티브).
   `g8-first-comparison.md` 4.4 와 같다

## 5. 실행 중 잡은 버그 둘 (기록)

둘 다 **조용히 틀리는** 종류였다. `TASKS.md` B 항목에 상세.

1. 초기 체크포인트에 `epoch` 키가 없어 `train.py:401` 에서 TypeError → `epoch: 0`
   저장으로 해결. 0 인 이유는 float 으로 시작해 기준선과 같은 에폭(60)에서 QAT 에
   들어가야 비교가 성립하기 때문이다
2. `train.py:797` 이 `model_args["bias"] = args.use_bias` 로 bias 를 항상 명시해
   넘기고 기본값이 False 라, 진입점의 `setdefault` 가 **한 번도 발동하지 않았다.**
   체크포인트의 bias 9개가 버려진 채 경고 한 줄만 남았다 → 진입점이 강제로
   덮어쓰고, 셀 명령에 `--use-bias` 를 넣고, 도구가 assert 한다
   ⚠️ **위 결과는 이 수정 이후의 실행이다** (bias 가 실제로 얹힌 상태).
