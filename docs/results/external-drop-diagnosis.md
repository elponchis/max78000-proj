# 외부 세트 낙폭 원인 진단 — 혼합음 / 코덱

배경: `external-eval.md`. 시험셋 @300/h 문턱값을 고정했을 때 외부 세트에서
클래스별 recall 이 6~36% 로 떨어졌다. 재학습·다운로드 없이 **기존 시험셋을
변형해** 그 낙폭이 재현되는지 본다. PC 평가다.

## 1. 사전 등록 (2026-10-05, 실행 전에 고정)

**대상**: ④(5시드), ①′(3시드), 후보 다 `u800`(3시드). 문턱값은 체크포인트별
**원래 시험셋 @300/h 값 고정**. 평가 경로는 `eval_external.py` 와 같다
(변형한 창을 샤드로 감싸 `collect_logits` 를 그대로 부른다).

**(가) 혼합음.** 시험셋 이벤트 창 e 에 시험셋 배경 창 b 를 섞는다 (int8 영역).

    g = rms(e) / (rms(b) · 10^(SNR/20)),   y = clip(round(e + g·b), −128, 127)

- 이벤트 레벨은 그대로 두고 **배경을 스케일**한다. SNR = +20 / +10 / +5 / 0 dB.
- 배경 풀 두 가지를 따로: **일반**(index note 가 `hard_neg:` 로 시작하지 않는 창)
  / **하드 네거티브**. int8 0 비율 > 0.5 인 배경 창은 풀에서 뺀다 (키우면
  양자화 잡음만 커진다). 짝은 시드 78000 으로 한 번 정한다 (전 조건 공통).
- **같은 split(test) 안에서만** 섞는다. 배경 창 자체는 바꾸지 않으므로 오경보는
  원래 시험셋과 같다 — 보는 것은 이벤트 recall 뿐이다.
- **기준 조건**: 클래스마다, 일반 풀에서 섞은 뒤 **int8 0 비율 중앙값이 외부
  세트의 그 클래스(v1 양성) 중앙값에 가장 가까운 SNR**. recall 을 보고 고르지
  않는다.

**(나) 코덱.** 시험셋 전체(이벤트 + 배경)를 왕복 변환한다. 저장 행(1.224초)을
클래스별로 이어 붙여 한 번에 부호화하고, 복호 뒤 상호상관으로 지연을 맞춰
다시 자른다.
- `aac`: 44.1 kHz 스테레오(같은 채널 복제) AAC-LC 128 kbps — 유튜브 itag 140 상당
- `opus`: 48 kHz 스테레오 Opus 160 kbps — itag 251 상당
- 대조 `resample`: 44.1 kHz 무손실 왕복 (리샘플러만의 영향)
- 대조 `aac32`: 모노 32 kbps (유튜브보다 훨씬 나쁜 조건 — 상한 확인용)
- 무손실 16 kHz 왕복이 **비트 단위로 원본과 같아야** 실행한다.
- 배경도 변환하므로 고정 문턱값에서의 오경보/h 를 함께 적는다.

**(다) 결합.** (가)의 기준 조건(일반 풀)으로 섞은 뒤 `aac` 왕복. 이벤트만.

**재현율(= 낙폭을 얼마나 재현했는가).** 구성 c, 클래스 k 에 대해

    재현 비 = (R_시험셋 − R_조건) / (R_시험셋 − R_외부[v1 정의])

요약값은 3구성 × 4클래스 12칸의 **평균**이다.

**읽는 법 (고정)**
- (가) 기준 조건의 요약 재현 비 ≥ 0.5 → **"배경 혼합으로 같은 크기의 낙폭이
  재현된다"** (⚠️ 표현 개정 2026-10-05: 실행 전 문구는 "혼합음이 주원인" 이었다.
  이 실험은 충분조건만 보이므로 원인을 단정하는 말을 쓰지 않기로 했다.
  문턱(0.5)과 계산은 그대로다)
- (가) < 0.5 이고 (나) `aac` 또는 `opus` ≥ 0.5 → **"코덱"**
- 둘 다 < 0.5 → **"출처·라벨 차이 등 미확인"** ((다)가 ≥ 0.5 여도 "두 요인의
  합으로는 재현된다" 까지만 쓴다)
- SNR 별 표 전체를 싣는다. 기준 조건 밖의 SNR 에서 외부 수준까지 떨어지는지는
  **관찰로만** 적는다 (기준 조건을 사후에 바꾸지 않는다).

**알고 있는 한계 (실행 전)**
- 시험셋 창은 이미 16 kHz·int8 이다. 원본 고음질 → 코덱 → 16 kHz 가 아니라
  int8 → 코덱 → int8 이라 양자화 잡음이 코덱 입력에 들어간다.
- 섞는 배경은 FSD50K 계열이다 (유튜브의 음악·말소리와 구성이 다르다).
- 재현되더라도 **충분조건**을 보인 것이다 — 외부 세트의 실제 원인이 그것이라는
  직접 증거는 아니다.

## 2. 결과

실행 2026-10-05. 무손실 16 kHz 왕복은 비트 단위로 원본과 같았다 (사전 등록 조건
충족). 코덱 지연은 네 조건·다섯 클래스 모두 0 샘플로 측정됐다. 배경 풀: 일반
1,421창 / 하드 네거티브 1,456창 (0 비율 > 0.5 인 961창 제외). 이벤트 창 1,369개.

### 2.0 판정 (사전 등록 규칙 그대로)

> **코덱은 원인에서 배제됐다. 배경 혼합으로 같은 크기의 낙폭이 재현된다
> (충분조건이며 직접 증거는 아니다).**
>
> (가) 기준 조건의 요약 재현 비 0.795 (문턱 0.5). (나) 코덱은 AAC 0.006 /
> Opus 0.001 이고 유튜브보다 훨씬 나쁜 AAC 32 kbps 모노에서도 0.032 다.
> (다) 결합 0.793 은 (가)와 같다 — 코덱이 더하는 것이 없다.

**이 판정이 말하는 것과 말하지 않는 것**

1. **고르지 않다.** 0.795 는 12칸의 평균이고 클래스마다 크게 다르다.
   - `siren` (기준 0 dB): 0.78~0.99.
   - `scream` (기준 +10 dB): 0.51~0.80.
   - `glass` (기준 0 dB): **1.36~1.74 — 외부 세트보다 더 떨어진다.** 유리
     파손은 0.3초 과도음이라 창 전체 RMS 기준 0 dB 는 과하다. 0 비율로 고른
     기준 조건이 glass 에서는 너무 센 혼합이다. glass 가 평균을 끌어올렸다.
   - `dog_bark` (기준 +20 dB): **0.04~0.08 — 거의 재현되지 않는다.** 0 비율
     기준으로는 +20 dB 가 맞지만 그 조건에서 recall 은 1~2pp 만 내려간다.
     dog_bark 의 외부 낙폭(31~32pp)은 **이 기준 조건으로는 설명되지 않는다.**
   glass 를 1.0 으로 자르면 평균은 0.66 이고, 여전히 0.5 를 넘는다.
2. **관찰 (기준 조건 밖, 판정에 쓰지 않는다)**: 전 클래스에 같은 SNR 을 주면
   일반 배경 **+10 dB 에서 0.64, +5 dB 에서 0.95** 다. 즉 외부 세트의 낙폭은
   "창 RMS 기준 SNR +5~+10 dB 의 혼합" 과 같은 크기다. dog_bark 도 +5 dB 에서
   0.82~1.08 로 재현된다 — dog_bark 는 0 비율이 SNR 을 잘 반영하지 못한
   것으로 보인다 (짖는 소리 사이가 원래 비어 있다. 확인하지 않았다).
3. **배경 종류는 큰 차이가 없다.** 하드 네거티브가 일반보다 0.03~0.08 더
   떨어뜨린다.
4. **입력 표현과 무관하다.** ④·①′·후보 다가 같은 SNR 에서 비슷한 비율로
   떨어진다 (+10 dB 에서 0.49 / 0.66 / 0.77). 로그 멜이 혼합음에 더 강하지
   않다 — 오히려 재현 비가 조금 높다. 구성 순위는 전 조건에서 유지된다.
5. **충분조건이다.** "시험셋에 배경을 섞으면 외부 세트만큼 떨어진다" 를
   보였을 뿐, 외부 세트의 낙폭이 실제로 혼합음 때문이라는 직접 증거는 아니다.
   라벨 오류·출처 차이가 같이 있을 수 있다 (외부 세트는 청취 검증 전이다).
6. **v1 학습 데이터에는 혼합음이 거의 없다.** 증강은 시간 이동과 게인뿐이고
   MSnoise 혼합은 v1 에 넣지 않았다 (CLAUDE.md 5장 규칙 6). 이벤트 창의
   배경은 대부분 원본 클립의 조용한 구간이거나 −10 dB 이하의 채움 베드다.
   → 설계안: `dataset-v2-design.md`.

> **표 읽는 법.** 재현 비 = (시험셋 recall − 그 조건의 recall) / (시험셋 recall −
> 외부 세트 recall[v1 정의]) — 0 이면 안 떨어졌고 1 이면 외부 세트만큼 떨어졌다.
> **기준 조건**의 SNR 은 클래스별로 siren 0 dB / glass 0 dB / scream +10 dB /
> dog_bark +20 dB (일반 배경, int8 0 비율로 정했다).

### 2.6 v2 (배경 혼합 증강) 결과가 이 진단에 주는 것 (2026-10-06 추가)

v2 (`dataset-v2-design.md` 9절)로 학습한 모델은 **혼합 시험셋의 재현율을 같은
오경보에서 회복시켰지만** (혼합 시험셋은 배경 창이 그대로라 고정 문턱값에서
오경보가 v1 과 같다; +10 dB 에서 glass +17~+34pp, scream +12~+39pp) **외부 세트는
회복시키지 못했다** — 시험셋 문턱값 고정에서의 외부 macro-F1 향상은 외부
오경보 증가와 섞여 있고, 외부 오경보를 같게 맞추면 v2 − v1 의 CI 가 0 을
포함한다.

> **따라서 배경 혼합은 외부 낙폭의 충분조건일 뿐이고, 설명되지 않은 요인이
> 남아 있다.** 2.0절의 판정("코덱 배제, 배경 혼합으로 같은 크기의 낙폭 재현")은
> 그대로이나, "혼합을 학습시키면 외부 낙폭이 줄어든다" 는 **성립하지 않았다.**
> 남은 후보는 출처 차이(유튜브 대 Freesound), 청취 검증 전 라벨, 창 배치 규칙
> 차이(이벤트 중심 대 RMS 최대), 그리고 FSD50K 배경과 다른 혼합음 종류다.
