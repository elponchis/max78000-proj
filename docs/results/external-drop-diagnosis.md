# 외부 세트 낙폭 원인 진단 — 혼합음 / 코덱

배경: `external-eval.md`. 시험셋 @300/h 문턱값을 고정했을 때 외부 세트에서
클래스별 recall 이 6~36% 로 떨어졌다. 재학습·다운로드 없이 **기존 시험셋을
변형해** 그 낙폭이 재현되는지 본다. PC 평가다.

## 1. 사전 등록 (2026-10-05, 실행 전에 고정)

**대상**: ④(5시드), ①′(3시드), 후보 다 `u800`(3시드). 문턱값은 체크포인트별
**원래 시험셋 @300/h 값 고정**. 평가 경로는 `eval_external.py` 와 같다
(변형한 창을 샤드로 감싸 `collect_logits` 를 그대로 부른다).

**(가) 혼합음.** 시험셋 이벤트 창 e 에 시험셋 배경 창 b 를 섞는다 (int8 영역).

    g = rms(e) / (rms(b) · 10^(SNR/20)),   y = clip(round(e + g·b), −128, 127)

- 이벤트 레벨은 그대로 두고 **배경을 스케일**한다. SNR = +20 / +10 / +5 / 0 dB.
- 배경 풀 두 가지를 따로: **일반**(index note 가 `hard_neg:` 로 시작하지 않는 창)
  / **하드 네거티브**. int8 0 비율 > 0.5 인 배경 창은 풀에서 뺀다 (키우면
  양자화 잡음만 커진다). 짝은 시드 78000 으로 한 번 정한다 (전 조건 공통).
- **같은 split(test) 안에서만** 섞는다. 배경 창 자체는 바꾸지 않으므로 오경보는
  원래 시험셋과 같다 — 보는 것은 이벤트 recall 뿐이다.
- **기준 조건**: 클래스마다, 일반 풀에서 섞은 뒤 **int8 0 비율 중앙값이 외부
  세트의 그 클래스(v1 양성) 중앙값에 가장 가까운 SNR**. recall 을 보고 고르지
  않는다.

**(나) 코덱.** 시험셋 전체(이벤트 + 배경)를 왕복 변환한다. 저장 행(1.224초)을
클래스별로 이어 붙여 한 번에 부호화하고, 복호 뒤 상호상관으로 지연을 맞춰
다시 자른다.
- `aac`: 44.1 kHz 스테레오(같은 채널 복제) AAC-LC 128 kbps — 유튜브 itag 140 상당
- `opus`: 48 kHz 스테레오 Opus 160 kbps — itag 251 상당
- 대조 `resample`: 44.1 kHz 무손실 왕복 (리샘플러만의 영향)
- 대조 `aac32`: 모노 32 kbps (유튜브보다 훨씬 나쁜 조건 — 상한 확인용)
- 무손실 16 kHz 왕복이 **비트 단위로 원본과 같아야** 실행한다.
- 배경도 변환하므로 고정 문턱값에서의 오경보/h 를 함께 적는다.

**(다) 결합.** (가)의 기준 조건(일반 풀)으로 섞은 뒤 `aac` 왕복. 이벤트만.

**재현율(= 낙폭을 얼마나 재현했는가).** 구성 c, 클래스 k 에 대해

    재현 비 = (R_시험셋 − R_조건) / (R_시험셋 − R_외부[v1 정의])

요약값은 3구성 × 4클래스 12칸의 **평균**이다.

**읽는 법 (고정)**
- (가) 기준 조건의 요약 재현 비 ≥ 0.5 → **"혼합음이 주원인"**
- (가) < 0.5 이고 (나) `aac` 또는 `opus` ≥ 0.5 → **"코덱"**
- 둘 다 < 0.5 → **"출처·라벨 차이 등 미확인"** ((다)가 ≥ 0.5 여도 "두 요인의
  합으로는 재현된다" 까지만 쓴다)
- SNR 별 표 전체를 싣는다. 기준 조건 밖의 SNR 에서 외부 수준까지 떨어지는지는
  **관찰로만** 적는다 (기준 조건을 사후에 바꾸지 않는다).

**알고 있는 한계 (실행 전)**
- 시험셋 창은 이미 16 kHz·int8 이다. 원본 고음질 → 코덱 → 16 kHz 가 아니라
  int8 → 코덱 → int8 이라 양자화 잡음이 코덱 입력에 들어간다.
- 섞는 배경은 FSD50K 계열이다 (유튜브의 음악·말소리와 구성이 다르다).
- 재현되더라도 **충분조건**을 보인 것이다 — 외부 세트의 실제 원인이 그것이라는
  직접 증거는 아니다.
