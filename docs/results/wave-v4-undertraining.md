# ④(원본 파형)의 v4·v4+D 격차는 적합이 아니라 일반화에서 생긴다 — 출처별 학습 재현율 (2026-10-11)

사용자 지시(2026-10-11, 5항): ④ 가 v4·v4+D 에서 보인 이상(시험셋 siren recall 25.6 → 8.4% 등)을 **출처별 학습 재현율**과 함께
따로 정리한다. **결론 문장(사용자 확정): "④ 는 학습 창을 85~93% 맞추며, 격차는 적합이 아니라 일반화에서 생긴다."** 논문의 근거 자료다. 도구 `tools/wave_v4_diag.py`, 수치 `data/external_eval/wave_v4_diag.json`, 로그
`data/logs-local/wave_v4_diag.out`. 해석은 관찰에 한정하고 원인 실험은 하지 않았다.

## 1. 무엇을 재었나

각 판(v3.1 / v4 / v4+D)의 ④ 와 간격 400 체크포인트(시드 1~3, 채점에 쓴 `qat_best`)를 **그 판의 학습 창**(v3.1: `SafeSoundV31`
17,223창, v4·v4+D: `SafeSoundV4` 16,669창)에 **무증강**으로 돌려 argmax 재현율을 클래스 × 출처(FSD50K / US8K / ESC-50 / AudioSet;
출처는 clip_id 형식과 인덱스 note 로 판별)로 냈다. 문턱값·증강이 끼지 않으므로 "학습 창 자체를 맞추는가" 만 본다.
함께 (가) 학습 로그 마지막 에폭(149)의 Top1 — **증강이 걸린** 학습 배치(KD 판은 라벨 행만)·검증·시험(argmax) — 과
(나) 시험셋 @300/h 재현율(testL, `eval-baseline-change.md` 5.2)을 붙였다.

## 4. 읽기 (관찰)

1. **④ 는 학습 창을 85~93% 맞춘다 — 격차는 적합이 아니라 일반화에서 생긴다.** "학습 데이터를 못 외운" 것이 아니다. 간격 400
   (98~99%)과의 적합 차이는 10 pp 안팎이고 세 판에서 비슷한데, 시험셋 @300/h 재현율 차이는 그보다 훨씬 크다(아래 ③).
2. **증강이 걸리면 격차가 벌어진다.** 마지막 에폭의 학습 Top1(게인 ±12 dB·shift·배경 혼합이 걸린 배치)은 ④ 63.6 / 67.1 /
   82.4 대 간격 400 80.9 / 87.7 / 90.6 — 무증강 재현율 격차(약 10 pp)보다 큰 **15~20 pp** 다. 즉 ④ 의 적합이 낮아지는 곳은
   학습 창이 아니라 **증강된 학습 분포**다 — 일반화 격차의 한 단면이다. 로그 멜은 게인을 평행이동으로 받지만(`CLAUDE.md` 2장) 원본 파형은 그렇지 않다 —
   이 문서는 그 관찰까지만 적고 분리 실험은 하지 않았다.
3. **시험셋 siren @300/h 의 붕괴(25.6 → 8.4%)는 학습 적합도 변화가 아니다.** v3.1 → v4 에서 siren 학습 창은 그대로(1,195)이고
   ④ 의 siren 학습 재현율도 88.9 → 86.0 으로 거의 같다. 바뀐 것은 고정 오경보 지점에서의 동작점이다 — 같은 모델의 argmax 시험
   Top1 은 오히려 64.7 → 67.5 로 올랐다. 외부 siren 도 14.9 → 7.7 로 같은 방향이다. 증류(v4+D)에서는 학습 재현율이 거의 그대로
   (87.1)인데 시험셋 siren 이 56.5, 외부 siren 이 31.8 로 회복한다. **@300/h 재현율은 적합도가 아니라 마진(배경 대비 점수 차)의
   함수**이고, ④ 는 그 마진이 판에 따라 크게 흔들린다 — 시드 폭도 ④ 가 넓다(v4 siren 81.5~89.7 대 간격 400 97.9~98.2).
4. **AudioSet 창이 두 구성 모두에서 가장 어렵다.** ④ siren AudioSet 82~85% 대 FSD50K·US8K 91~94%, dog_bark AudioSet 67~72% 대
   86~95%. 간격 400 도 dog_bark AudioSet 이 가장 낮고 v4+D 에서 79.9% 로 더 내려간다(교사 로짓이 hard 라벨과 다른 창을
   배경 쪽으로 밀었을 가능성 — 확인하지 않았다). AudioSet 창은 영상 오디오라 FSD50K 계열보다 잡음·겹침이 많다.
5. **v4+D 에서 ④ 는 이벤트 창을 배경으로 더 많이 보낸다** (7.4 → 11.5%; 간격 400 1.7 → 4.3%). 증류가 argmax 적합도를
   올리지 않으면서(③ 참조) 배경 쪽 확률을 키운 결과로 보이며, 시험셋 ④ scream 하락(27.0 → 20.1 pp, 조건 F 미충족)과 방향이 같다.

## 5. 한계

- 학습 재현율은 argmax·무증강이다. 실제 학습 손실은 증강 하 KD(T=2, α=0.5) 손실이라 이 표가 손실 자체를 보여주지는 않는다.
- 출처 판별은 clip_id 형식(US8K `fsid-class-occ-slice`, ESC-50 `fold-fsid-take-target`)과 인덱스 note(`audioset;…`) 기준이다.
- 원인(게인 증강 대 표현, 마진 보정)은 분리하지 않았다 — 사용자 결정으로 조사 대상이 아니다. 논문에는 "④ 는 학습 창을 85~93% 맞추며,
  격차는 적합이 아니라 일반화에서 생긴다 — 고정 오경보 지점의 재현율이 판·시드에 따라 크게 흔들린다" 로 적는다.
