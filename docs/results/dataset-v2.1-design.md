# 데이터셋 v2.1 — 채택 판정 **기각** (0/5), 본 표는 **v2.1** (7절 일탈 규칙, 조건 2·4 5/5) — 2026-10-07

작성 2026-10-06. 근거: `dataset-v2-design.md` 9절 (v2 채점). v2 에서 두 가지가
나왔다 — (가) 외부 세트의 향상이 **외부 오경보 증가와 섞여** 있고, (나)
배경끼리 섞은 창에서 v2 의 발화율이 원래 배경보다 **높다** (v1 은 낮았다).
둘 다 같은 방향이다: v2 는 "혼합 흔적" 을 이벤트 단서로 조금 배웠다.

## 1. 변경은 하나

**배경 클래스 창에도 다른 train 배경 창을 섞는다** — 이벤트 창과 **같은 확률
(0.5), 같은 SNR 범위 (창 전체 RMS 기준 0~+20 dB 균등)** 로.

- v2 는 `_mix_noise()` 가 `target == background` 면 그대로 돌려보냈다
  (`datasets/safesound.py`, kat_mix 5번 항목). 그래서 학습 중 "두 소리가 겹친
  창" 은 **전부 이벤트 라벨**이었다 — 겹침 자체가 이벤트의 단서가 된다.
- v2.1 은 배경 창도 절반이 겹친 창이 되므로 겹침은 라벨과 무관해진다.
- 배경 + 배경에서 "SNR" 은 자기 자신을 이벤트 자리에 둔 식 그대로다
  (`g = rms(자기) / (rms(상대)·10^(SNR/20))`). 라벨은 background 그대로.
- 상대 배경은 같은 풀(train background, int8 0 비율 ≤ 0.5)에서 뽑고 자기
  자신은 제외한다. 그 외(순서·포화·게인 뒤 혼합)는 v2 와 같다.
- 구현은 `_mix_noise()` 의 조건 한 줄과 `SafeSound*V21` 데이터셋 등록, kat_mix 에
  "배경 창도 확률 0.5 로 바뀐다" 항목 추가. 반나절.

## 2. 사전 등록할 채택 조건 (승인 시 고정)

기준은 **v1** 이다 (v2 는 참고열). 구성마다 같은 시드 수, Welch 95% CI.

| # | 조건 | 통과 기준 |
|---|---|---|
| 1 | 외부 세트 macro-F1, 시험셋 @300/h 문턱값 고정 (v2 의 조건 1) | v2.1 − v1 CI 하한 > 0 |
| 2 | 기존 시험셋 macro-F1 @300/h (v2 의 조건 2) | v2.1 − v1 CI 하한 ≥ −0.02 |
| **3** | **외부 오경보를 맞춘 비교**: 외부 배경 기준 @300/h 문턱값에서의 외부 macro-F1 | v2.1 − v1 CI 하한 ≥ −0.02 **그리고** 점 추정 ≥ 0 |
| **4** | **배경끼리 섞은 창의 발화율** (시험셋 문턱값, `diag/bgbg`) | 시드 평균이 원래 배경 발화율(2.06%) + 0.5pp 이하, 즉 **≤ 2.6%** |

- 3 의 보조 지점은 264창 중 5창으로 정해져 CI 가 넓다. 그래서 "CI 하한 > 0" 을
  요구하지 않고 **"해롭지 않다 + 점 추정이 내려가지 않는다"** 로 둔다. 이 조건의
  역할은 조건 1 의 향상이 오경보 증가만으로 생긴 것이 아님을 확인하는 것이다.
- 4 는 v2 에서 2.7~3.6% 였다. v1 은 1.5~2.0%.
- **채택**: 돌린 구성의 **과반**이 네 조건을 모두 충족. 못 채우면 v2 와 같은 문구
  ("이 표본 크기로 확인하지 못함" / "낮아졌다" 구분).
- 외부 세트 결과를 보고 SNR 범위·확률·문턱값을 조정하지 않는다. 한 번 돌린다.
- 보고 항목은 v2 와 같다 (클래스별 recall·F1, 혼합 시험셋, 순위).

| 안 | 구성 | 학습 횟수 | 예상 |

다는 가와 같은 뒷단·비슷한 결과라 뒤로 미룬다. 셋에서 채택되면 나머지 둘을
이어서 돌린다 (추가 약 7시간).

## 5. 사전 등록 (2026-10-06 승인, 학습 시작 전 커밋. 실행 후 바꾸지 않는다)

### 5-a. 대상과 순서

5개 구성 전부. 순서: **④ → 간격 400 → 후보 가 → 후보 다 → ①′.** 앞의 셋이 끝나면
중간 채점을 보고한다. 종료 코드는 audit_runs.py 로 확인한다.

### 5-b. 시드 수

| 구성 | v2.1 시드 | v1·v2 시드 | v2.1 − v2 비교에 쓰는 시드 |
|---|---:|---:|---|
| ④ | 5 | 5 | 1~5 |
| 간격 400 | **5** | 3 | 1~3 만 |
| 후보 가 | 3 | 3 | 1~3 |
| 후보 다 | 3 | 3 | 1~3 |
| ①′ | **5** | 3 | 1~3 만 |

**시드를 늘린 이유**: v2 에서 "간격 400 대 ①′ 동등(±0.02)" 판정이 CI 폭 때문에
통과하지 못했다 (+0.012 [−0.024, +0.049]; ①′ v2 의 3시드 폭이 0.030). 3시드의
Welch CI 는 차이가 0.01 이어도 ±0.03 이 나온다. 5시드면 같은 분산에서 폭이 약
0.6배로 준다. **규칙**: v2(또는 v1)와 비교할 때는 **같은 시드끼리만**(1~3) 쓴다.
5시드 결과는 **v2.1 안의 구성 간 비교**(5-d)에만 쓴다 — 시드 수가 다른 두 집단을
섞어 비교하면 분산 추정이 어긋난다.

### 5-c. 본 표 규칙

- v2.1 이 2절의 채택 조건을 충족하면 **본 표는 v2.1**, v1 과 v2 는 부록.
- 충족하지 못하면 기존 규칙(v2 설계안 8-d)대로 **본 표는 v2** 이고, 한계 절에
  **배경 미혼합 결함**(이벤트에만 혼합 → 혼합 흔적이 이벤트 단서)과 **외부
  오경보 증가**(시험셋 문턱값에서 외부 배경 발화 증가)를 적는다.
- 채택 단위는 2절대로 "돌린 구성의 과반(5개 중 3개)이 네 조건을 모두 충족".

### 5-d. v2.1 에서 다시 판정할 것

시험셋 macro-F1 @300/h, Welch 95% CI. v1·v2 판정과 나란히 표로 낸다.

1. 간격 400 대 ①′ 동등 (±0.02) — 5시드 대 5시드.
2. 후보 가·다 대 ①′ — 3시드 대 5시드 (v2.1 안의 비교).
3. 후보 가·다 대 ④ — 3시드 대 5시드.
4. 구성 순위 — 시험셋과 외부 세트 (시험셋 문턱값 고정 + 외부 배경 기준 지점).

### 5-e. 고정

외부 세트 결과를 보고 SNR 범위·확률·문턱값을 바꾸지 않는다. **v2.1 뒤에는
증강을 더 고치지 않는다.** 구현 뒤 kat_mix.py 에 네 항목을 추가해 확인한다:
배경 창이 설정한 확률로 섞이는가, 배경 풀이 train 배경뿐인가, 자기 자신과 섞이지
않는가, 시험셋은 무증강인가.

## 6. 혼합 적용 비율 — 설정 0.5, 실효 (2026-10-06, 학습 중 확인. 코드 수정 없음)

kat_mix 9번 항목의 947/2000 (47.4%) 이 0.5 에서 약 2.4 표준편차 낮아 다시 셌다.
다른 난수 시드(20261006), 창마다 20,000회. "호출" 은 `mix_int8` 이 실제로 불린
비율(= 난수가 확률 문턱을 통과한 비율), "변화" 는 출력이 입력과 달라진 비율이다.

| 대상 | 호출 | 변화 (**실효**) | 호출됐으나 무변화 |
|---|---:|---:|---:|
| 배경 고정 창 (kat 과 같은 창, RMS 6.8 LSB) | 49.64% | 49.64% | 0 |
| 배경 창 무작위 (학습 배경 전체 9,577창) | 49.77% | **45.92%** | 769 (RMS 0 인 창 240 + 스케일한 배경이 1 LSB 미만 529) |
| 배경 창 무작위 (풀 안 7,035창) | 49.80% | 49.58% | 44 |
| 이벤트 창 무작위 | 49.73% | **49.27%** | 91 |

- **난수 경로는 0.5 가 맞다** (호출 49.6~49.8%, 20,000회의 표준오차 0.35%p).
  947/2000 은 표본 잡음이었다 — 같은 창을 20,000회 돌리면 49.64% 다.
- **실효 비율은 설정보다 낮고, 건너뛰는 경로는 둘이다** (코드 그대로 둔다):
  1. `mix_int8` 은 **자기 창의 RMS 가 0** 이면 섞지 않고 돌려준다 (`re <= 0`).
     배경 창의 약 1.2% (디지털 무음 창. 이벤트 창에는 없다).
  2. 조용한 자기 창 + 높은 SNR 이면 **스케일한 배경이 1 LSB 미만**이라 반올림
     뒤 입력과 같다 — 호출은 됐지만 결과가 없다. 배경 2.6%, 이벤트 0.5%.
     풀 밖 배경(int8 0 비율 > 0.5)은 혼합 **대상**으로는 들어가므로 (풀은 상대를
     뽑는 쪽만 거른다) 배경 쪽에서 더 자주 생긴다.
  3. 자기 자신 제외는 재추첨 루프가 있어 건너뛰지 않는다. 풀이 비는 경우 없음.
- **기록**: 배경 혼합 **설정 0.5, 실효 약 0.46** (학습 배경 전체 기준) /
  이벤트 혼합 **설정 0.5, 실효 약 0.49**. v2 의 이벤트 혼합도 같은 코드라
  실효 약 0.49 다. 차이의 원인은 무음·저레벨 창이고 설계 의도(그런 창은 섞어도
  int8 에서 같다)와 어긋나지 않으므로 고치지 않는다.

⚠️ **이 절은 사전 등록(5절) 뒤에, ④·간격 400·후보 가의 중간 결과를 본 뒤에

### 7.1 일탈 내용 — 본 표 선택 규칙 (5-c 철회)

5-c 의 **"충족하지 못하면 본 표는 v2" 를 철회한다.** 새 규칙:

- v2.1 이 **조건 2(시험셋 비열등: v2.1 − v1 CI 하한 ≥ −0.02)** 와 **조건 4(배경+배경
  혼합 창 발화율 ≤ 2.6%)** 를 **5개 구성 중 3개 이상**에서 충족하면, 조건 1·3
  충족 여부와 **무관하게 본 표는 v2.1** 이다.
- 그렇지 않으면 **본 표는 v1** 이다.
- **v2 는 어느 경우에도 본 표로 쓰지 않는다** — 배경 미혼합 결함(이벤트에만
  혼합 → 겹침이 이벤트 단서, `dataset-v2-design.md` 9.4절).

**채택 판정 자체는 바꾸지 않는다.** 2절의 네 조건·과반 규칙으로 원래대로
내리고, 조건 1·3 을 못 채우면 **"외부 세트 향상은 확인하지 못했다"** 고 적는다.
본 표 선택과 채택 판정은 이 절부터 별개의 문장이다.

### 7.2 일탈 사유

(a) **v2 의 지름길 결함이 코드로 확인됐다.** `_mix_noise()` 가 배경 클래스 창을
    건너뛰어 학습 중 "겹친 창" 이 전부 이벤트 라벨이었다. 배경끼리 섞은 창의
    발화율 상승(1.5~2.0 → 2.7~3.9%)과 외부 오경보 증가가 그 결과다. 결함이
    확인된 판을 본 표로 둘 수 없다.
(b) **조건 3 의 CI 하한 기준은 그 지점의 분해능으로는 통과하기 어렵다.** 외부
    배경 기준 @300/h 지점은 264창 중 5창으로 정해져 v2.1 − v1 의 95% CI 폭이
    ±0.05~0.12 다. 차이가 0 이상이어도 하한 ≥ −0.02 를 넘기 어렵다 — 설계 때
    폭을 과소평가했다.
(c) **본 표 선택 기준을 외부 세트와 무관한 조건 2·4 로만 둔다.** 외부 세트는
    시험 전용이고 분해능이 거칠다. 본 표가 어느 판인가는 기존 시험셋의
    비열등성과 결함 해소 여부로 정한다.
