|---|---|---|

## 3. 증류 설계 (v4+D)

### 3.1 교사

**PANNs CNN14 16 kHz** (`Cnn14_16k_mAP=0.438.pth`) — 같은 체크포인트. 교사 출력을 5클래스로 만드는 방법 두 가지 중
**(가) 선형 프로브**를 권고한다.

| 방식 | 5클래스 점수 | 장점 | 단점 |
|---|---|---|---|
| (가) **선형 프로브** (`ceiling_check.py --mode probe`, 2048 임베딩 고정 + 선형층, v4 학습셋 라벨로 학습) | 로짓 5개, 소프트맥스 | 우리 정의(군중 제외, 하드 네거티브)를 배운 교사. 로짓 스케일이 자연스럽다 | 교사도 우리 라벨을 본다 — 라벨 오류가 있으면 같이 배운다 (v4 정리가 그래서 먼저다) |
| (나) 제로샷 (`zeroshot` 점수: 묶음 최대, 배경 = 1 − max) | 확률 비슷한 값 5개 | 라벨 독립 | 분포가 아니라 각 클래스 sigmoid 최대라 합이 1이 아니고, Yell·Shout·Dog 가 우리 정의와 어긋난다 (`label-audit.md` 1절 real31 오경보) |

선형 프로브는 `ceiling_check.py --mode probe` 에 자리만 있고 **구현 전**이다 (`ceiling-check.md` 2.5). 3단계에서 구현한다 —
임베딩 2048 → 선형 5, v4 학습셋 라벨·클래스 가중치로 학습, 시험셋 @300/h 로 교사 자체 성능을 먼저 적는다.
교사 로짓은 **v4 학습 창(무증강)에 대해 한 번 계산해 캐시**한다 (`data/processed/safesound_v4/teacher/<cls>/shard_NNNN.npy`,
창당 float32 5개). PANNs 는 22 ms/창이라 17k 창에 6분이다.

### 3.2 학생과 손실

- 학생: **간격 400** 과 **④** (사전 등록 대상과 같다), 3시드.
- 손실 = (1 − α)·CE(하드 라벨, 클래스 가중치) + α·T²·KL(softmax(교사/T) ‖ softmax(학생/T)).
  α = 0.5, T = 2 로 시작한다 (g8-c 의 0.7 / 4 는 교사 로짓 스케일 문제와 얽혀 있었다). ai8x-training 의
  `--kd-teacher` 경로는 교사 모델을 온라인으로 돌리므로 쓰지 않고, **캐시된 로짓을 Dataset 이 같이 내는 방식**으로
  (`SafeSoundV4D` 로더가 `(x, (y, t_logits))` 를 내고 손실 래퍼가 받는다). `wrap_teacher.py`·`calib_teacher.py` 의
  검사(유효 클래스 수, 스케일)를 그대로 쓴다.
- ⚠️ **증강 불일치**: 교사 로짓은 무증강 창에서 계산한 것인데 학생은 증강(게인·shift·배경 혼합)된 창을 본다. 게인·shift
  는 교사 판단을 거의 바꾸지 않지만 **배경 혼합(mix_prob)은 바꿀 수 있다**. 1차는 그대로 가고, 혼합된 창에서는
  α 를 0 으로 (하드 라벨만) 두는 변형을 2차 후보로 적어 둔다. 온라인 교사(에폭마다 PANNs)는 17k × 22 ms ≈ 6 분/에폭
  × 150 = 15 시간이라 하지 않는다.
- QAT 정책·스케줄·옵티마이저·에폭(150)은 그대로.

### 3.3 g8-c 에서 배운 것 (적용)

1. 교사 로짓 스케일을 **전역 상수 하나**로 보정하고 유효 클래스 수를 적는다 (`calib_teacher.py`). 1.0 = one-hot 이면
   증류가 아니다.
2. **입력 표현이 다른 교사→학생은 해로울 수 있다** (① 멜 교사 → ④ raw 학생 −0.074). PANNs 도 멜 입력이다. 그래서
   간격 400(멜 학생)에서 먼저 보고, ④ 는 같이 돌리되 해로우면 그대로 보고한다 — ④ 에서 해로운 것은 예측된 결과다.
3. 증류 체크포인트는 `kat_teacher.py` 가 보는 교사 일관성 검사를 통과해야 한다.

## 7. 라벨 없는 창 — 받아 둔 AudioSet 클립 전체를 교사 확률만으로 학습

### 7.1 양

`~/safesound-external/train_v2/raw/` 의 클립 **2,689개** (16 kHz mono, 길이 중앙값 10.01 s, 최소 3.02 s, 합계 26,294 s
= 7.3 시간; 영상 2,689개, 영상당 1클립). 1초 창·250 ms 간격으로 자르면 **94,424창** (1초 간격이면 23,640창).

| 항목 | 값 |
|---|---|
| 창 수 (hop 250 ms) | 94,424 (= 학습셋 17k 의 5.5배) |
| int8 샤드 (1.2 s 저장, 마진 포함) | 94,424 × 19,584 B ≈ **1.85 GB** (디스크 여유 899 GB) |
| 교사 로짓 캐시 5 × float32 | 1.9 MB (527 × float16 전부 두면 100 MB — 프로브를 다시 학습할 때 재계산을 피하려면 임베딩 2048 × float16 = 387 MB 를 둔다) |
| 교사 계산 시간 | 22 ms/창 (6스레드, `label_audit.py` 실측) × 94k = **약 35분** (임베딩 포함 같은 패스) |

**외부 세트 영상과 겹침 — 다시 확인 (2026-10-09)**: raw 클립의 ytid 2,689개 ∩ `external_v1/meta.csv` ytid = **0**,
∩ `sampling_list.csv`(889) = **0**, ∩ AudioSet **eval strong 전체** 영상 = **0**. 빌드 때 `kat_v3.py` 3번 검사(분리)를
라벨 없는 샤드에도 돌린다.

### 7.2 학습 방식

- 라벨 없는 창은 **하드 라벨이 없다**. 손실은 KL(교사 소프트 타깃 ‖ 학생) 만 (α = 1). 라벨 있는 창은 3.2 그대로.
- 교사 타깃은 무증강 창에서 계산한 캐시. 라벨 없는 창에는 **게인·shift 만** 걸고 배경 혼합은 걸지 않는다 (혼합하면
  교사 타깃과 어긋난다 — 혼합할 거면 혼합 뒤 창에 교사를 온라인으로 돌려야 하는데 94k × 22 ms = 35 분/에폭이라 안 한다).
- **에폭 비용을 묶는다**: 매 에폭 라벨 없는 창에서 **17k 창(= 라벨 있는 창 수)을 무작위로 뽑아** 라벨 있는 창과 1:1 로
  섞는다 (에폭마다 다시 뽑아 ~5.5 에폭에 전부 한 번씩 돈다). 에폭당 창 수가 2배라 학습 시간도 약 2배 — 간격 400
  약 150분/실행, ④ 약 75분. 전부 넣으면(6.5배) 간격 400 이 8시간/실행이라 하지 않는다.
- 교사 타깃이 **배경 쪽으로 치우친다** (라벨 없는 10초 클립의 대부분은 이벤트가 아니다 — train_v2 의 1,243 배경 세그먼트
  + 이벤트 세그먼트의 이벤트 밖 구간). 클래스 가중치는 라벨 있는 창에만 적용하고, 라벨 없는 창의 KL 에는 가중치를 두지
  않는다 (교사 분포 자체가 정보다). 교사 타깃의 클래스별 평균 확률을 빌드 때 적는다.
- 창 선별 없음 (에너지·0 비율 필터도 걸지 않는다 — 조용한 창도 교사가 "배경" 이라고 알려 준다). 단 int8 전부 0 인 창은
  뺀다 (교사·학생 모두 정보가 없다).

### 7.3 데이터 양 효과 — 절반 조건 (v4+D+U½)

라벨 없는 **영상을 결정적 해시로 반(1,345 영상 ≈ 47k창)** 만 쓴다. 에폭당 뽑는 창 수는 U 와 같은 17k 로 두어
**학습 비용·배치 구성은 같고 다양성만 다르게** 한다. 그러면 U − U½ 의 차이가 "영상(출처) 수의 효과" 가 된다.

| 비교 | 묻는 것 | 판단 (사전 등록) |
|---|---|---|
| U − D | 라벨 없는 창이 도움이 되나 | 조건 A·B 의 CI 하한 > 0 |
| U − U½ | 영상 수를 두 배로 하면 더 오르나 | 외부 F1 점 추정 ≥ +0.02 **이고** CI 하한 > −0.02 면 "더 받을 가치 있음" 으로 보고. 그 미만이면 "포화" |
| U½ − D | 절반으로도 도움이 되나 | 참고 |

AudioSet 을 더 받을지는 이 표로 **사용자가** 정한다 (다운로드는 외부데이터 세션). 3시드 분해능(반폭 ~0.05)에서 +0.02 는
못 가리는 크기이므로, "포화" 판정은 "효과가 없다" 가 아니라 "이 분해능으로 안 보인다" 로 적는다.

### 7.4 순서와 시간 (5절에 더함)

| 단계 | 내용 | 시간 |
|---|---|---|
| 3′ | 라벨 없는 창 샤드 빌드 + 교사 임베딩·로짓 캐시 + 분리 KAT | 빌드 10분 + 교사 35분 |
| 4′ | v4+D+U: 간격 400 ×3 (→ ④ ×3 은 U 가 간격 400 에서 통과했을 때만) | 간격 400 약 7.5시간 (+④ 약 4시간) |
| 4″ | v4+D+U½: 같은 구성·시드 | 같음 |

v4 → v4+D → U·U½ 순서이고, 각 단계는 보고 후 멈춘다. U 와 U½ 는 같은 밤에 이어 돌릴 수 있게 체인 하나로 묶되, 앞 단계
(v4+D)가 미통과면 시작하지 않는다.

## 8. 교사(PANNs 선형 프로브)의 학습 데이터

- **학습**: v4 의 **라벨 있는 학습 창만** — FSD50K 계열(US8K·ESC-50 포함) 학습 창 + AudioSet train_v2 의 v3.1 규칙 창,
  2절의 정리(PANNs < 0.02 제외, 아기 울음 → 배경)를 적용한 뒤의 것. 무증강 창의 PANNs 임베딩 2048 → 선형 5, 손실은 v4
  클래스 가중치 CE. **외부 세트는 쓰지 않는다** (학습에도, 모델 선택에도).
- **모델 선택(에폭·L2)**: 학습 창을 **원본 ID 단위**(FSD50K fsid / ytid)로 10% 떼어 검증한다. 기존 시험셋도 쓰지 않는다
  — 교사를 시험셋에 맞추면 학생의 시험셋 수치가 오염된다.
- **보고**: 프로브를 고정한 뒤 기존 시험셋 @300/h 와 외부 세트(real31L) 를 **한 번** 채점해 교사 자체 성능으로 적는다
  (학생이 넘어야 할 상한이 아니라 참조점). zero-shot(외부 0.72)보다 낮으면 (나) zero-shot 교사로 바꾼다 — 그 결정은
  시험셋이 아니라 **검증 분할** 수치로 한다.
- 라벨 없는 창(7절)의 교사 타깃도 같은 프로브로 만든다. 프로브를 다시 학습하면 캐시를 전부 다시 만든다 (임베딩 캐시가
  있으면 로짓만 다시 계산, 1분).

## 9. 바꾸지 않는 것 / 한계

- 외부 세트를 보고 정의·규칙·문턱값을 고치지 않는다. 청취 확정은 모델 출력을 보지 않고 한다.
- PANNs 0.02 제외는 **학습용**에만 쓴다. 시험 정답은 청취다. 둘을 섞으면 "PANNs 식 정답에 PANNs 교사로 맞춘" 순환이 된다 —
  시험 정답에 PANNs 가 전혀 안 들어가는 것이 이 설계의 전제다. (단 기존 시험셋 siren·scream·dog_bark 창은 v1 선별 때
  PANNs 묶음 필터를 통과한 창이라는 역사적 편향이 남는다 — 한계에 적는다.)
- 증류 교사의 소리 정의가 AudioSet 이다. 우리 정의(군중 제외 등)와 다른 곳은 (가) 프로브가 흡수하지만 완전하지 않다.
- 청취 판정자 1인. 대조 창의 O 비율로 청취 기준을 점검한다.
