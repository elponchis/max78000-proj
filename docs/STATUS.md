## 3. 확정 원칙 (어기지 말 것)

### 3.1 자(잡음 눈금) 규칙

- **주 판정: Welch t 95% CI** (`compare_runs --seed-diff "설명:계열A:계열B"`).
  등분산 가정 없음 — 계열별 sd 가 5배 차이난다 (④ 0.0238 vs ① 0.0049).
- **range × 3 은 병기만.** 파형 계열에서 검정력이 너무 낮다 (0.055 × 3 = 0.16).
- range 를 쓸 때는 **비교 쌍의 두 계열 중 큰 자**를 쓴다
  (`--delta "…:x:y:A+B"` 로 주면 max 를 택한다).
- **CI 가 0 을 포함 = "차이 없다" 가 아니라 "이 표본으로는 못 가른다".**
- 시드는 독립이어도 **같은 데이터**를 쓴다 — 데이터 표본 변동은 CI 에 없다.

### 3.2 포화 원칙

> **평가·펌웨어 경로는 포화(`np.clip`) 하나로 고정.
> 되돌리기/포화 혼합은 _증강(학습 전용)_ 에만 허용.**

게인 스윕의 +게인 판은 **포화 판을 배포 기준**으로 읽는다.
펌웨어는 랩어라운드가 아니라 포화로 구현한다 (CLAUDE.md 7장, MSDK 버그).

### 3.3 원본 수 기준 (A~E)

`siren` 예:

### 3.5 표기 규칙

- **추정치는 "추정" 이라고 쓴다.** 사이클 수(합성 로그)와 CPU 명령 수

## 5.7 음량 정규화 2단계 — chain19 (2026-10-02) ★ **정규화 라인 종료**

int16 샤드(`data/processed/safesound16`, 실기기 스케일 ×8128)에서 **int8 변환
전**에 창 단위 peak 정규화. 모델·학습 설정은 ④ 와 같다. 연산은 정수뿐이다
(`datasets/safesound.py` `norm16`, KAT `tools/kat_norm16.py`):

```
G = clamp((96 << 16) / max(peak,1), 1, GMAX << 10);  y = sat8((x16*G + 32768) >> 16)
```

샤드 대조(`tools/verify_shards16.py`): 인덱스 10개 전부 바이트 일치, int8 로

- 규칙 1 (CI > 0): **둘 다 불성립** → 규칙 2 "이 표본으로는 못 가른다"

| 사고 | 원인 | 방지책 |
|---|---|---|

계속 늘린다.

9. **`echo "$(date) … (exit $?)"` 는 종료 코드를 지운다** (2026-10-01).
   명령 치환이 먼저 실행되어 `$?` 가 `date` 의 것(항상 0)으로 덮인다.
   chain11·14 의 "(exit 0)" 은 전부 `date` 의 종료 코드였다 — 학습이
   실패했어도 0 으로 찍혔을 것이다. chain15 부터 `local rc=$?` 로 먼저
   담는다. **게이트가 실패를 통과로 읽으면 게이트가 아니다** (3번과 같은 류).

10. **`kat_entrypoints.py` 가 새 모델 파일을 조용히 건너뛰었다**
