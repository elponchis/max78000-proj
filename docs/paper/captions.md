## 그림 1 — 판단 1회 추정 에너지와 정확도 (`docs/paper/fig1_acc_energy.png`)

왼쪽은 시험 데이터 의 macro-F1, 오른쪽은 외부 데이터 (AudioSet) 의 F1 이다. 색은 전처리 위치 — 검정 전처리 없음, 주황 NPU 전처리, 파랑 CPU 전처리 (log-mel) — 이고 흑백 인쇄를 위해 마커 모양도 구성마다 다르다. 마커 위치는 (가) 데이터시트 전력 기준 에너지, 가로 막대는 공개 전력값 범위 ((가) 데이터시트 / (나) 선행연구 (Moss / Ulkar & Okman) / (나′) Moss / Moosmann), 세로 막대는 시드 표준편차 (n=3). CPU log-mel 네 점은 프레임 간격 (62.5 / 50 / 25 / 16 ms) 을 에너지 순으로 이었다. 별표(*)가 붙은 NPU 근사 log 는 보드에서 재지 않았고 지연을 합성 사이클로 추정한 점이다 (빈 마커). NPU 전처리 (Gabor 필터뱅크) 는 선형 전처리(512탭 Gabor 필터뱅크 + 프레임 안 에너지 적분)를 NPU 로 옮기고 정수 로그만 CPU 에 남긴 구성으로, 두 네트워크를 동시 적재한 보드 실측이다 (CPU 구간은 NPU 전원이 켜진 채 돌아 P_load 로 계산). 큰 고리와 점선은 파레토 앞면 — 점 추정(데이터시트 에너지, 시드 평균) 기준으로 에너지가 같거나 작으면서 정확도가 같거나 높은 다른 점이 없는 구성 (시험 데이터: NPU 전처리 (Gabor 필터뱅크), CPU log-mel, 간격 62.5 ms (멜 32), CPU log-mel, 간격 50 ms, CPU log-mel, 간격 25 ms, CPU log-mel, 간격 16 ms; 외부 데이터: NPU 전처리 (Gabor 필터뱅크), CPU log-mel, 간격 62.5 ms (멜 32), CPU log-mel, 간격 50 ms, CPU log-mel, 간격 25 ms, CPU log-mel, 간격 16 ms). 정확도는 데이터 v4+D, 시드 1~3 평균 (막대 = 시드 표준편차), 오경보 300회/h 가 되는 문턱값을 시험 데이터 배경에서 잡고 외부 데이터 (AudioSet) 에도 같은 문턱값을 썼다. 시험 데이터 정답은 사람 청취로 확정한 것(유리 70창·비명 134창 양성, 채점 창 4,965), 외부 데이터 (AudioSet) 정답도 청취 확정 (비명 양성 53, 배경 구간 264창). 지연은 MAX78000FTHR 에서 v4+D 시드 1 가중치로 1000회 측정한 최악값 (전원 투입 직후, 코어 100 MHz / CNN 50 MHz, 바쁜 대기; 슬립·유휴·가중치 적재 미포함). 에너지는 전부 추정(실측 지연 × 공개 전력)이며 측정값이 아니다 — E = 전처리 시간·P_cpu + (적재 + 출력)·P_load + 추론·P_npu, 전력값과 출처는 paper_config.json.

## 그림 2 — 판단 1회 지연 분해 (`docs/paper/fig2_latency_breakdown.png`)

왼쪽은 NPU 로 추론하는 7개 구성의 판단 1회 지연을 CPU 전처리 / 입력 적재(+출력) / NPU 추론으로 나눈 것이다 (막대 위 숫자 = 합계 ms). NPU 전처리 (Gabor 필터뱅크) 의 CPU 전처리는 NPU 필터뱅크 출력의 |cos|+|sin|·8위치 합·정수 로그이고, 입력 적재에는 두 네트워크 전환(층 레지스터 재설정)이 들어 있다. NPU 근사 log 는 추정 (적재·출력은 원본 파형 (전처리 없음) 실측, 추론은 합성 사이클 ÷ CNN 클럭). 오른쪽은 같은 가중치를 CMSIS-NN 으로 Cortex-M4F 에서 돌린 CPU 추론 (Cortex-M4F) 으로, 축이 다르며 점선은 판단 주기 250 ms 다 (CPU 추론 (Cortex-M4F) 은 주기의 90% 를 추론에 쓴다). 지연은 MAX78000FTHR 에서 v4+D 시드 1 가중치로 1000회 측정한 최악값 (전원 투입 직후, 코어 100 MHz / CNN 50 MHz, 바쁜 대기; 슬립·유휴·가중치 적재 미포함). 에너지는 전부 추정(실측 지연 × 공개 전력)이며 측정값이 아니다 — E = 전처리 시간·P_cpu + (적재 + 출력)·P_load + 추론·P_npu, 전력값과 출처는 paper_config.json.

## 그림 3 — 클래스별 재현율 (`docs/paper/fig3_recall_by_class.png`, 부록 전체판 `docs/paper/fig3_recall_by_class_all.png`)

왼쪽 시험 데이터, 오른쪽 외부 데이터 (AudioSet). 막대는 구성별 시드 평균 ± 표준편차, 점선은 대형 모델 (PANNs) (CNN14 zero-shot) 을 같은 정답·같은 문턱값 규칙으로 채점한 기준선이다 (시험 F1 0.845, 외부 F1 0.702). 논문판은 원본 파형 (전처리 없음), CPU log-mel, 간격 62.5 ms (멜 32), CPU log-mel, 간격 16 ms 세 구성, 부록판은 7개 구성 전부. 정확도는 데이터 v4+D, 시드 1~3 평균 (막대 = 시드 표준편차), 오경보 300회/h 가 되는 문턱값을 시험 데이터 배경에서 잡고 외부 데이터 (AudioSet) 에도 같은 문턱값을 썼다. 시험 데이터 정답은 사람 청취로 확정한 것(유리 70창·비명 134창 양성, 채점 창 4,965), 외부 데이터 (AudioSet) 정답도 청취 확정 (비명 양성 53, 배경 구간 264창).

## 그림 4 — 데이터 개선 단계별 외부 데이터 F1 (`docs/paper/fig4_edition_ext_f1.png`)

학습 데이터를 단계적으로 고치면서 (초기 데이터 → +배경 혼합 → +AudioSet 추가 → +라벨 정정 → +증류, 누적) 원본 파형 (전처리 없음) 과 CPU log-mel, 간격 25 ms 두 구성을 각 단계에서 3시드씩 학습하고, 모든 단계를 **같은** 외부 데이터 (AudioSet) 와 같은 청취 확정 정답으로 다시 채점한 F1 이다 (문턱값은 각 단계의 시험 데이터 배경 300회/h). 막대 = 시드 표준편차. 단계 설명:

- 초기 데이터: FSD50K·UrbanSound8K·ESC-50을 칩 입력 규격(16 kHz, int8)으로 재가공
- +배경 혼합: 학습 시 이벤트 창과 배경 창 모두에 다른 배경음을 SNR 0~20 dB로 섞는 증강
- +AudioSet 추가: AudioSet 학습 분할의 실제 환경 녹음 구간 추가(비명은 Screaming 구간만)
- +라벨 정정: 청취로 대부분 틀린 것이 확인된 유형의 학습 창 제외(유리·비명 중 대형 모델 점수가 매우 낮은 창)
- +증류: 대형 모델(PANNs) 기반 교사의 출력을 라벨 없는 창 약 9.4만 개를 포함해 함께 학습
