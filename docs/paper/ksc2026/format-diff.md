NPU 전처리 (Gabor 필터뱅크)는 사전에 정한 목표(원본 파형 구성 초과 또는 CPU log-mel 62.5 ms 구성과 동등)는 넘지 못했다(원본 파형 구성 대비 ‑0.026 [‑0.082, +0.030], CPU log-mel 62.5 ms 구성 대비 ‑0.111 [‑0.162, ‑0.060]). 추정 에너지는 원본 파형 구성보다 세 전력 출처 모두에서 적지만(데이터시트 39 대 71 μJ, Moosmann 52 대 78 μJ; 판단 1회 1.85 ms 대 2.53 ms), CPU log-mel 62.5 ms 구성과는 비슷한 에너지(데이터시트 기준 39 대 43 μJ)에서 시험 macro-F1이 0.11 낮다. 보드에서 가속기 출력·CPU 특징·최종 로짓이 호스트와 비트 일치했고, CPU 몫 0.70 ms의 80%는 가속기 메모리에서 int32 출력 2,048개를 읽어 8위치 합산까지 하는 시간, 20%는 정수 로그였다.<br><br>대역·프레임 수를 늘린 NPU 전처리 변형 3종은 정확도가 올랐으나 에너지가 더 빠르게 늘어 세 전력 출처 모두에서 CPU 전처리 곡선 아래에 머물렀다(그림 1). 시험 macro-F1 0.655~0.690 (표 1), 추정 에너지 39에서 71~133 μJ. 늘어난 비용은 CPU의 가속기 메모리 읽기(46~51%)와 NPU 연산(39~45%)이 비슷하게 나눴다.<br><br>최적점은 중간에 있다. 전처리는 병목이 아니라 데이터 축소 단계였고, NPU가 원시 샘플 전량을 처리하는 순간 그 이득이 사라진다. CPU log-mel 62.5 ms 구성은 원본 파형 구성보다 시험 macro-F1 +0.085 [+0.035, +0.135], 외부 F1 +0.099 [+0.056, +0.142]로 유의하게 높고, 추정 에너지는 데이터시트 기준으로는 적고 Moosmann 기준 78 대 78 μJ로 같다. log-mel이 16,384 샘플을 512 값으로 줄여 NPU 입력 적재(1.09 → 0.13 ms)와 추론(1.44 → 0.53 ms)이 줄었다(그림 2). 대신 CPU 전처리 2.26 ms가 늘어 판단 1회 지연은 2.93 대 2.53 ms로 비슷하지만, 줄어든 적재·추론 구간의 에너지(데이터시트 기준 71 → 23 μJ)가 늘어난 CPU 구간(20 μJ)보다 커서 추정 에너지는 43 대 71 μJ로 줄었다. 프레임 간격을 좁힐수록 정확도는 오르지만(25 → 16 ms의 차이 ‑0.016 [‑0.030, ‑0.002]) 전처리가 지연의 2/3를 차지해 에너지가 6배가 되며, 그림 1의 파레토 앞면은 NPU 전처리 (Gabor 필터뱅크) → CPU log-mel 간격 62.5 → 50 → 25 → 16 ms이다. NPU 전처리 (Gabor 필터뱅크)와 62.5 ms 구성은 에너지 차이가 약 4 μJ로 사실상 정확도에서 갈리고, 원본 파형과 NPU 근사 log는 지배된다. 외부 데이터에서도 앞면 순서가 같았다(그림 1(b)).<br><br>대형 모델 기준선. PANNs(CNN14)는 같은 정답·문턱값 규칙에서 시험 macro-F1 0.845이고, CPU log-mel 16 ms 구성은 그 99%에 이른다. |
| **5. 한계와 결론 → 4. 한계 + 5. 결론 및 향후 과제** | [1] 한계. 에너지는 직접 계측하지 않은 추정값이며 전력 출처에 따라 결론의 강도가 다르다(CPU log-mel 62.5 ms 구성의 우위는 '적다' 와 '같다' 사이). 시드가 3개라 신뢰구간이 넓다. 정답 청취는 저자 1인이다. 비명과 환호의 경계는 음향만으로 가를 수 없어 비명 재현율은 그 모호성을 포함한다. 시험 데이터 배경의 절반이 하드 네거티브라 오경보율은 실배치보다 부풀려져 있다. NPU 전처리 (Gabor 필터뱅크) 의 CPU 구간은 가속기 전원이 켜진 채 돌므로 적재 전력으로 보수적으로 계산했고, 가속기 메모리 읽기를 DMA 로 바꾸면 더 줄 수 있다. 향후 과제로, CPU 몫의 80%를 차지하는 읽기와 위치 합산을 NPU 에서 수행하려면 8비트 출력에 맞춘 재학습이 필요하다.<br><br>[2] 평균 전력. 판단 1회 에너지를 평균 전력으로 옮기면(데이터시트 기반 추정), 디지털 마이크를 유지하는 대기 전력이 대부분을 차지한다. I2S 를 살린 가장 깊은 대기 모드의 고정 전류(LPM 0.64 mA [1])로 구한 대기 전력 하한 1.9 mW 이상이면 CPU log-mel 62.5 ms 구성의 판단 비용은 평균 전력의 17% 이하, CPU log-mel 16 ms 구성은 54% 이하다. 반면 NPU 없이 CPU 로 추론하면 현 구성의 대기 전력 상한 11 mW 에서도 판단 비용이 평균 전력의 42% 이상을 차지한다. 즉 NPU 는 거친 log-mel 구성에서 판단 비용을 평균 전력의 작은 몫으로 낮추고, 전처리 구성 간 에너지 차이는 대기 전력을 줄일수록 평균 전력에 더 크게 드러난다. RISC-V 코어를 상시 게이트로 두어 이벤트 후보에서만 판단하는 설계의 이득 상한은 판단 비용 전부로, 현 대기 모드에서 약 2%, 가장 깊은 대기 모드에서도 CPU log-mel 62.5 ms 구성 기준 17%를 넘지 않는 것으로 추정된다. RISC-V 로 전처리를 옮기는 안도 FPU 없는 60 MHz 코어의 전력이 Cortex-M4F 의 0.6~1.0배로 추정되어 손익분기 전처리 지연 2.2~4.2 ms 를 지키기 어려워 제외했다.<br><br>[3] 결론. NPU 탑재 MCU 에서 '전처리를 전부 가속기로' 는 환경음 감지에서 최적이 아니다. 지원 연산이 제한된 가속기에 비선형 전처리를 옮기는 시도는 정확도도 에너지도 얻지 못했고, 선형 부분만 옮긴 구성은 원본 파형 구성보다 에너지를 줄였지만 CPU 전처리의 저에너지 구성과 비슷한 에너지에서 정확도를 잃어 앞면 끝에 머물렀으며, 작은 CPU 전처리로 데이터량을 줄인 뒤 작은 모델을 가속기에 올리는 구성이 정확도–에너지 전선 위에 있었다. 이 칩에서는 어떤 연산을 가속기에 두느냐보다, 가속기에 들어가는 데이터율이 구성의 우열을 더 잘 설명했다. | • 에너지 추정과 평균 전력. 에너지는 직접 계측하지 않은 추정값이며 전력 출처에 따라 결론의 강도가 다르다(CPU log-mel 62.5 ms 구성의 우위는 '적다' 와 '같다' 사이). NPU 전처리 (Gabor 필터뱅크)의 CPU 구간은 가속기 전원이 켜진 채 돌므로 적재 전력으로 보수적으로 계산했다. 판단 1회 에너지를 평균 전력으로 옮기면(데이터시트 기반 추정) 디지털 마이크를 유지하는 대기 전력이 대부분이라, 가장 깊은 대기 모드(하한 1.9 mW)에서도 CPU log-mel 62.5 ms 구성의 판단 비용은 평균 전력의 17% 이하, 16 ms 구성은 54% 이하인 반면 NPU 없이 CPU로 추론하면 현 대기 전력 상한 11 mW에서도 42% 이상이다.<br><br>• 통계·정답. 시드가 3개라 신뢰구간이 넓고, 정답 청취는 저자 1인이며, 비명과 환호의 경계는 음향만으로 가를 수 없어 비명 재현율은 그 모호성을 포함한다.<br><br>• 배치 조건. 시험 데이터 배경의 절반이 하드 네거티브라 오경보율은 실배치보다 부풀려져 있다.<br><br>NPU 탑재 MCU에서 '전처리를 전부 가속기로' 는 환경음 감지에서 최적이 아니다. 지원 연산이 제한된 가속기에 비선형 전처리를 옮기는 시도는 정확도도 에너지도 얻지 못했고, 선형 부분만 옮긴 구성은 정확도 이득 없이 앞면 끝에 머물렀으며, 작은 CPU 전처리로 데이터량을 줄인 뒤 작은 모델을 가속기에 올리는 구성이 정확도–에너지 전선 위에 있었다. 이 칩에서는 어떤 연산을 가속기에 두느냐보다, 가속기에 들어가는 데이터율이 구성의 우열을 더 잘 설명했다. NPU 전처리의 CPU 몫 80%는 log를 NPU에서 수행할 수 없어 int32 중간 결과를 CPU로 읽어 오는 데이터 이동이었고, 전처리의 이점은 증분 계산을 전제로 한다.<br><br>전력계로 에너지를 직접 계측해 전력 출처 간 차이를 없애고, 실배치 분포의 배경과 복수 판정자 정답으로 데이터셋을 보강하며, 읽기·위치 합산의 NPU 이전(8비트 출력 재학습)과, RISC-V 보조 코어를 활용해 대기 전력을 줄이는 저전력 수집 경로를 검토한다. |
